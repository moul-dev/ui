# Moul UI Documentation (`docs`)

The documentation site for **Moul UI**, built with **Astro Starlight**. English lives at the root and Khmer under `/km/`.

---

## 🏗️ Architecture

- **Framework**: [Astro](https://astro.build) with [Starlight](https://starlight.astro.build), static output
- **Locales**: `root` (English) and `km` (Khmer, set in Noto Sans Khmer), configured in `astro.config.mjs`
- **Live previews**: `src/components/ComponentPreview.astro` renders `<moul-*>` tags written directly in MDX. `data-props='{…}'` on an element assigns JSON as JavaScript properties (chart data, columns, items).
- **Library source**: `@moul-dev/ui` and `@moul-dev/ui/style.css` are aliased to `../ui/src`, so previews always reflect the current source and hot-reload while you edit components.
- **Styling**: `src/styles/global.css` imports the library's token layer and maps Starlight's colors onto it.
- **Theme Studio**: `src/pages/theme.astro` (`/theme`) inspects and tunes the CSS tokens live.
- **No React**: `bun run build` first runs `scripts/verify-no-react.ts docs`, which fails if a React-ecosystem package appears in `package.json`.

## 📁 Content

```
src/content/docs/
├── index.mdx                 # Home page (splash)
├── docs/                     # Introduction, LLM guide, components/, blocks/
├── changelog/                # Release notes, one file per release (YYYY-MM-DD.mdx)
└── km/                       # Khmer mirror of the same tree
```

- **Component sidebar**: groups and order come from `src/categories.ts`, which mirrors the sandbox in `ui/src/sandbox.ts`. Add a new page's slug there.
- **Khmer pages**: every English page needs a counterpart under `km/` at the same path. Component pages keep the English body with a translated `title` and `description`; the introduction and LLM guide are fully translated.
- **Changelog**: list each new entry in the `Changelog` sidebar group in `astro.config.mjs`, and in both `changelog/index.mdx` files. `bun run bump --changelog` scaffolds the entry.
- **AI context files**: `public/llms.txt`, `public/llms-full.txt`, and `public/AGENTS.md` are generated by `bun run sync:llms --write` from the repository root. Do not edit them by hand.

## 🚀 Development

From the repository root:

```bash
# Docs dev server
bun run dev:docs

# Or the sandbox and docs together
bun run dev
```

### Type checking

```bash
bun --cwd docs types:check
```

### Building for production

```bash
bun run build:docs
bun --cwd docs preview   # serve the built site locally
```

The static site is written to `docs/dist`.
