## Highlights

This is the initial release of the **Moul UI** component library — a collection of accessible, beautifully styled React components built on top of [React Aria](https://react-spectrum.adobe.com/react-aria/) and [StyleX](https://stylexjs.com/).

### Core Components

- **Button** — Fully accessible button with multiple variants, sizes, and states
- **Alert** — Contextual alert messages with semantic color coding
- **InputOTP** — One-time password input with automatic focus management
- **Tag & TagGroup** — Tag components for categorization and filtering

### Foundation

- Built with **React Aria Components** for accessible structure and behavior
- **StyleX** for compile-time CSS-in-JS with zero runtime overhead
- Full **TypeScript** support with strict type checking
- RSC-compatible with `"use client"` banner in build output
