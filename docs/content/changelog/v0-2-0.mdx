## Highlights

The second release brings a wave of new interactive components and the launch of the official documentation site powered by Fumadocs.

### New Components

- **AlertDialog** — Confirmation dialogs with accessible focus trapping
- **Modal** — Full-featured modal dialogs with overlay and animations
- **Toast** — Notification toasts with auto-dismiss and action support
- **Form** — Form primitives with built-in validation and error handling
- **ComboBox** — Searchable select with tag-based multi-selection

### Documentation

- Launched the official Moul UI docs site built with **Fumadocs** and **Waku**
- Interactive component playground with live code editing
- Theme selector with custom color palette support

### Improvements

- Improved StyleX theme token system for consistent theming
- Better RSC compatibility across all components
