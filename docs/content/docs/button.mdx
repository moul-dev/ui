The `Button` component is a wrapper around React Aria's `Button` styled using StyleX. It supports multiple variants, states (hover, focus, pressed, disabled), and fully handles accessibility features like keyboard navigation and focus rings.

## Installation

To use `@moul-dev/ui` components in your project, install the library along with its peer dependencies:

```bash
bun add @moul-dev/ui react-aria-components @stylexjs/stylex
```

Make sure to configure your bundler (like Vite, Webpack, or Next.js) to support StyleX compilation.

---

## Usage

Import the button component and its styles into your React file:

```tsx
import { Button } from '@moul-dev/ui';
import '@moul-dev/ui/style.css'; // Load global and component StyleX outputs

export default function App() {
  return (
    <div style={{ display: 'flex', gap: '12px' }}>
      <Button variant="primary" onPress={() => alert('Clicked!')}>
        Primary Accent
      </Button>
      <Button variant="secondary">
        Secondary Glass
      </Button>
    </div>
  );
}
```

---

## Props

The `Button` component accepts all standard properties of React Aria's `Button` (such as `onPress`, `isDisabled`, `autoFocus`), plus the following custom properties:

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `variant` | `'primary' \| 'secondary'` | `'primary'` | The visual style variant of the button. |
| `children` | `ReactNode` | — | The content to render inside the button. |
