    ### Setting Up Cursor
    
    Cursor supports Project Rules via `.cursor/rules` or `.cursorrules`.

    <Steps>
      <Step>
        #### Create a Rule File
        
        Create `.cursor/rules/moul-ui.mdc` in your workspace:

        ```markdown title=".cursor/rules/moul-ui.mdc"
        ---
        description: Guidelines for building React components with @moul-dev/ui
        globs: "**/*.{ts,tsx}"
        alwaysApply: true
        ---

        When writing or editing React components:
        - Use @moul-dev/ui for all UI components, dialogs, forms, and charts.
        - Ensure `@moul-dev/ui/style.css` is imported at the application root.
        - Use `onPress` instead of `onClick` on `<Button>`, `<Link>`, and interactive triggers.
        - Use React Aria collection selection props (`selectedKey`, `onSelectionChange`).
        - For complete recipes and prop tables, refer to: https://moul.dev/AGENTS.md
        ```
      </Step>

      <Step>
        #### Add Documentation Docs URL
        
        In Cursor Settings &rarr; **Features** &rarr; **Docs**, add:
        - **URL**: `https://moul.dev/llms.txt` or your deployed docs URL
        - **Prefix**: `@moul-ui`
      </Step>
    </Steps>

## Golden Rules for AI Generation

When prompting an AI to generate interfaces with Moul UI, instruct the model to follow these core rules:

<Accordions>
  <Accordion title="1. Event Handlers: onPress vs onClick">
    Moul UI buttons and action triggers are built on React Aria and use `onPress`:
    
    ```tsx
    // ✅ Correct
    <Button variant="primary" onPress={() => handleSave()}>Save Changes</Button>

    // ❌ Incorrect
    <Button variant="primary" onClick={() => handleSave()}>Save Changes</Button>
    ```
  </Accordion>

  <Accordion title="2. Compound Component Architecture">
    Complex components like `Modal`, `AlertDialog`, `Card`, `Tabs`, `Table`, `Select`, and `Sidebar` use declarative compound subcomponents:
    
    ```tsx
    // ✅ Correct Modal structure
    <ModalOverlay isOpen={isOpen} onOpenChange={setIsOpen}>
      <Modal size="md">
        <ModalDialog>
          <ModalHeader><h3>Title</h3></ModalHeader>
          <ModalBody><p>Body text</p></ModalBody>
          <ModalFooter><Button onPress={() => setIsOpen(false)}>Done</Button></ModalFooter>
        </ModalDialog>
      </Modal>
    </ModalOverlay>
    ```
  </Accordion>

  <Accordion title="3. Accessible Labelling">
    All icon-only buttons **must** include an `aria-label`:
    
    ```tsx
    // ✅ Accessible
    <Button variant="ghost" aria-label="Delete project" onPress={handleDelete}>
      <TrashIcon />
    </Button>
    ```
  </Accordion>

  <Accordion title="4. Design Tokens & Theming">
    Custom branding is configured with CSS custom properties or `<ThemeProvider>`:
    
    ```css
    :root {
      --brand-hue: 250;               /* Primary hue */
      --brand-chroma-multiplier: 1.0; /* Saturation */
      --brand-radius-factor: 1.0;     /* Corner roundness */
      --brand-density-factor: 1.0;    /* Spacing & density */
    }
    ```
  </Accordion>
</Accordions>
