# Spinner

The `Spinner` component is an accessible animated indicator informing users of ongoing asynchronous processes and loading states.

## Preview

<ComponentPreview>
  <div className="flex items-center gap-6">
    <Spinner size="sm" aria-label="Loading small" />
    <Spinner size="md" aria-label="Loading medium" />
    <Spinner size="lg" aria-label="Loading large" />
    <Spinner size="xl" aria-label="Loading extra large" />
  </div>
</ComponentPreview>

## Import

```tsx
import { Spinner } from '@moul-dev/ui';
```

## Sizes

`Spinner` supports four standardized sizes: `sm`, `md` (default), `lg`, and `xl`.

```tsx
<Spinner size="sm" aria-label="Loading" />
<Spinner size="md" aria-label="Loading" />
<Spinner size="lg" aria-label="Loading" />
<Spinner size="xl" aria-label="Loading" />
```

## Accessibility

When using `Spinner`, always supply an `aria-label` or `aria-labelledby` attribute so screen readers announce the loading progress.

```tsx
<Spinner aria-label="Fetching dashboard telemetry..." />
```
