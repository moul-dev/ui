# Form

## Preview

<ComponentPreview>
  <FormDemo />

The `Form` component is built with React Aria and styled using StyleX.

## Import

```tsx
import { Form } from '@moul-dev/ui';
```

## Usage

Here is a basic example of how to use the `Form` component:

```tsx
import { Form } from '@moul-dev/ui';

export default function Example() {
  return (
    <Form>
      {/* Component content */}
    </Form>
  );
}
```
