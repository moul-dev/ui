# EmptyState

The `EmptyState` component removes boilerplate when presenting zero-data states, missing search results, unconfigured integrations, or empty lists. It supports both convenient direct props and composable subcomponents.

## Variants

`EmptyState` includes three standard layout styles:
- **`default`**: Transparent background and minimal padding, ideal for inline embedding within existing cards or table containers.
- **`card`**: Elevated background with clean border and subtle drop shadow.
- **`dashed`**: Dashed border with subtle neutral surface, commonly used for empty dropzones or unassigned items.

## Compound Composition

For maximum flexibility or custom slot layouts, compose using the subcomponents:

<ComponentPreview>
  <div className="w-full max-w-xl">
    <EmptyState variant="card" size="md">
      <EmptyStateIcon variant="primary">
        <svg viewBox="0 0 24 24" width="24" height="24" fill="none" stroke="currentColor" strokeWidth="2">
          <polygon points="12 2 15.09 8.26 22 9.27 17 14.14 18.18 21.02 12 17.77 5.82 21.02 7 14.14 2 9.27 8.91 8.26 12 2" />
        </svg>
      </EmptyStateIcon>
      <EmptyStateTitle as="h3">No favorites saved</EmptyStateTitle>
      <EmptyStateDescription>
        Bookmark repositories and dashboards to access them quickly here.
      </EmptyStateDescription>
      <EmptyStateActions>
        <Button size="sm" variant="primary">Explore Projects</Button>
        <Button size="sm" variant="outline">Learn More</Button>
      </EmptyStateActions>
    </EmptyState>
  </div>
</ComponentPreview>

```tsx
import {
  EmptyState,
  EmptyStateIcon,
  EmptyStateTitle,
  EmptyStateDescription,
  EmptyStateActions,
  Button,
} from '@moul-dev/ui';

export default function Example() {
  return (
    <EmptyState variant="card" size="md">
      <EmptyStateIcon variant="primary">
        <StarIcon />
      </EmptyStateIcon>
      <EmptyStateTitle as="h3">No favorites saved</EmptyStateTitle>
      <EmptyStateDescription>
        Bookmark repositories and dashboards to access them quickly here.
      </EmptyStateDescription>
      <EmptyStateActions>
        <Button size="sm" variant="primary">Explore Projects</Button>
        <Button size="sm" variant="outline">Learn More</Button>
      </EmptyStateActions>
    </EmptyState>
  );
}
```
