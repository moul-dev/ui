# ProgressBar

The `ProgressBar` component visually indicates the status of an ongoing operation, supporting determinate percentage values, indeterminate animated loading bars, custom metric labels, and semantic color variants.

## Import

```tsx
import { ProgressBar } from '@moul-dev/ui';
```

## Determinate vs Indeterminate

`ProgressBar` handles both bounded progress (e.g. `value={65}`) and indefinite loading states (`isIndeterminate={true}`):

<ComponentPreview>
  <div className="flex flex-col gap-5 w-full max-w-xl">
    <ProgressBar label="Determinate (45%)" value={45} />
    <ProgressBar label="Indeterminate (Loading...)" isIndeterminate />
  </div>
</ComponentPreview>

```tsx
// Determinate
<ProgressBar label="Determinate (45%)" value={45} />

// Indeterminate linear bar
<ProgressBar label="Indeterminate (Loading...)" isIndeterminate />
```

## Sizes and Shapes

Select from `sm` (4px), `md` (8px), and `lg` (12px) track heights, and `pill` or `square` corners:

<ComponentPreview>
  <div className="flex flex-col gap-5 w-full max-w-xl">
    <ProgressBar label="Small (sm) - Pill" value={40} size="sm" shape="pill" />
    <ProgressBar label="Medium (md) - Pill" value={60} size="md" shape="pill" />
    <ProgressBar label="Large (lg) - Pill" value={80} size="lg" shape="pill" />
    <ProgressBar label="Square Shape" value={70} shape="square" size="md" />
  </div>
</ComponentPreview>

```tsx
<ProgressBar label="Small (sm)" value={40} size="sm" shape="pill" />
<ProgressBar label="Medium (md)" value={60} size="md" shape="pill" />
<ProgressBar label="Large (lg)" value={80} size="lg" shape="pill" />
<ProgressBar label="Square Shape" value={70} shape="square" />
```

## Custom Value Labels

Use `valueLabel` to display formatted quantities, storage metrics, or steps:

<ComponentPreview>
  <div className="flex flex-col gap-4 w-full max-w-xl">
    <ProgressBar
      label="Cloud Storage"
      value={65}
      valueLabel="6.5 GB / 10 GB"
      showValueText
    />
    <ProgressBar
      label="Onboarding Wizard"
      value={60}
      valueLabel="Step 3 of 5"
      showValueText
      variant="accent"
    />
  </div>
</ComponentPreview>

```tsx
<ProgressBar
  label="Cloud Storage"
  value={65}
  valueLabel="6.5 GB / 10 GB"
  showValueText
/>

<ProgressBar
  label="Onboarding Wizard"
  value={60}
  valueLabel="Step 3 of 5"
  showValueText
  variant="accent"
/>
```
