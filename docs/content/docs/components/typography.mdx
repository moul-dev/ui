# Typography

## Preview

<ComponentPreview>
  <div className="flex flex-col gap-2">

The `Typography` component is built with React Aria and styled using StyleX.

## Import

```tsx
import { Typography } from '@moul-dev/ui';
```

## Usage

Here is a basic example of how to use the `Typography` component:

```tsx
import { Typography } from '@moul-dev/ui';

export default function Example() {
  return (
    <Typography>
      {/* Component content */}
    </Typography>
  );
}
```
