# Link

## Preview

<ComponentPreview>
  <Link href="#">Visit Khmer Dev</Link>
</ComponentPreview>

The `Link` component is built with React Aria and styled using StyleX.

## Import

```tsx
import { Link } from '@moul-dev/ui';
```

## Usage

Here is a basic example of how to use the `Link` component:

```tsx
import { Link } from '@moul-dev/ui';

export default function Example() {
  return (
    <Link>
      {/* Component content */}
    </Link>
  );
}
```

| Render Prop | CSS Selector |
| :--- | :--- |
| `isCurrent` <br/> Whether the link is the current item. | `[data-current]` |
| `isHovered` <br/> Whether the link is hovered. | `[data-hovered]` |
| `isPressed` <br/> Whether the link is pressed. | `[data-pressed]` |
| `isFocused` <br/> Whether the link is focused. | `[data-focused]` |
| `isFocusVisible` <br/> Whether the link is keyboard focused. | `[data-focus-visible]` |
| `isDisabled` <br/> Whether the link is disabled. | `[data-disabled]` |
