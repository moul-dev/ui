# Skeleton

The `Skeleton` component is an accessible animated placeholder used to render loading states that simulate layout content while data is loading.

## Preview

<ComponentPreview>
  <div className="flex items-center gap-4 w-72">
    <Skeleton variant="circle" />
    <div className="space-y-2 flex-1">
      <Skeleton variant="text" />
      <Skeleton variant="text" style={{ width: '80%' }} />
    </div>
  </div>
</ComponentPreview>

## Import

```tsx
import { Skeleton } from '@moul-dev/ui';
```

## Shape Variants

`Skeleton` supports three shape variants: `block` (default), `text`, and `circle`:

<ComponentPreview>
  <div className="flex flex-col gap-4 w-72">
    <div>
      <span className="text-xs text-neutral-400 mb-1 block">Block (variant="block")</span>
      <Skeleton variant="block" />
    </div>
    <div>
      <span className="text-xs text-neutral-400 mb-1 block">Text Line (variant="text")</span>
      <Skeleton variant="text" />
    </div>
    <div>
      <span className="text-xs text-neutral-400 mb-1 block">Circle / Avatar (variant="circle")</span>
      <Skeleton variant="circle" />
    </div>
  </div>
</ComponentPreview>

```tsx
// Rectangular block placeholder
<Skeleton variant="block" />

// Text line placeholder
<Skeleton variant="text" />

// Circular avatar / icon placeholder
<Skeleton variant="circle" />
```

## Multi-item Count

Use the `count` prop to render multiple stacked skeleton items with automatic spacing:

<ComponentPreview>
  <div className="w-72">
    <Skeleton variant="text" count={4} />
  </div>
</ComponentPreview>

```tsx
<Skeleton variant="text" count={4} />
```
