The `Table` component is built with React Aria and styled using StyleX.

## Import

```tsx
import { Table } from '@moul-dev/ui';
```

## Usage

Here is a basic example of how to use the `Table` component:

```tsx
import { Table } from '@moul-dev/ui';

export default function Example() {
  return (
    <Table>
      {/* Component content */}
    </Table>
  );
}
```
