# Pagination

The `Pagination` component enables users to navigate across large datasets divided into multiple pages. It features automatic sibling truncation ellipses, rows-per-page selection dropdowns, total summary counts, and complete ARIA landmark semantics.

## Basic Usage

Pass `page`, `totalPages`, and `onChange` for standard controlled pagination:

<ComponentPreview>
  <div className="flex flex-col gap-4 w-full max-w-xl">
    <Pagination page={3} totalPages={10} />
  </div>
</ComponentPreview>

```tsx
import { Pagination } from '@moul-dev/ui';
import { useState } from 'react';

export default function Example() {
  const [page, setPage] = useState(1);

  return (
    <Pagination
      page={page}
      totalPages={10}
      onChange={setPage}
    />
  );
}
```

## With Summary and Page Size Selector

Enable `showSummary` and `showPageSize` to provide complete data table navigation:

<ComponentPreview>
  <div className="flex flex-col gap-4 w-full max-w-2xl">
    <Pagination
      page={2}
      total={250}
      pageSize={10}
      showSummary
      showPageSize
      showFirstLast
      showPrevNext
    />
  </div>
</ComponentPreview>

```tsx
import { Pagination } from '@moul-dev/ui';
import { useState } from 'react';

export default function Example() {
  const [page, setPage] = useState(1);
  const [pageSize, setPageSize] = useState(10);

  return (
    <Pagination
      page={page}
      total={250}
      pageSize={pageSize}
      showSummary
      showPageSize
      showFirstLast
      showPrevNext
      onChange={setPage}
      onPageSizeChange={setPageSize}
    />
  );
}
```

## Compound Composition

You can build custom layouts by composing subcomponents inside `<Pagination>`:

```tsx
import {
  Pagination,
  PaginationContent,
  PaginationItem,
  PaginationLink,
  PaginationPrevious,
  PaginationNext,
  PaginationEllipsis,
  PaginationSummary,
} from '@moul-dev/ui';

export default function CustomPagination() {
  return (
    <Pagination page={3} totalPages={10}>
      <PaginationSummary>Page 3 of 10</PaginationSummary>
      <PaginationContent>
        <PaginationItem>
          <PaginationPrevious />
        </PaginationItem>
        <PaginationItem>
          <PaginationLink page={1} />
        </PaginationItem>
        <PaginationItem>
          <PaginationEllipsis />
        </PaginationItem>
        <PaginationItem>
          <PaginationLink page={3} isActive />
        </PaginationItem>
        <PaginationItem>
          <PaginationEllipsis />
        </PaginationItem>
        <PaginationItem>
          <PaginationLink page={10} />
        </PaginationItem>
        <PaginationItem>
          <PaginationNext />
        </PaginationItem>
      </PaginationContent>
    </Pagination>
  );
}
```
