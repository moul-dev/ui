# ToggleButton

## Preview

The `ToggleButton` component is built with React Aria and styled using StyleX.

## Import

```tsx
import { ToggleButton } from '@moul-dev/ui';
```

## Usage

Here is a basic example of how to use the `ToggleButton` component:

```tsx
import { ToggleButton } from '@moul-dev/ui';

export default function Example() {
  return (
    <ToggleButton>
      {/* Component content */}
    </ToggleButton>
  );
}
```
