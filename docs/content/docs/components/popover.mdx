# Popover

## Preview

The `Popover` component is built with React Aria and styled using StyleX.

## Import

```tsx
import { Popover } from '@moul-dev/ui';
```

## Usage

Here is a basic example of how to use the `Popover` component:

```tsx
import { Popover } from '@moul-dev/ui';

export default function Example() {
  return (
    <Popover>
      {/* Component content */}
    </Popover>
  );
}
```
