# Card

The `Card` component is a flexible container built with React Aria and styled using StyleX. It supports multiple design variants, sizing presets, and section borders.

## Import

```tsx
import { Card, CardHeader, CardBody, CardFooter } from '@moul-dev/ui';
```

## Divided Layout

By default, card headers, bodies, and footers flow continuously without separation lines. Passing the `divided` boolean prop adds subtle separator lines between sections.

<ComponentPreview>
  <Card className="w-80" divided>
    <CardHeader>Divided Card</CardHeader>
    <CardBody>Borders separate the header, body, and footer sections.</CardBody>
    <CardFooter>
      <Button size="sm">Action</Button>
    </CardFooter>
  </Card>
</ComponentPreview>

```tsx
<Card divided>
  <CardHeader>Divided Card</CardHeader>
  <CardBody>Borders separate the header, body, and footer sections.</CardBody>
  <CardFooter><Button size="sm">Action</Button></CardFooter>
</Card>
```

## Sizes

Choose between different sizing presets to customize block and inline paddings:

### Small (`sm`)
Compact spacing suitable for dense layouts or list grids.
```tsx
<Card size="sm">...</Card>
```

### Medium (`md`)
Balanced standard spacing (default).
```tsx
<Card size="md">...</Card>
```

### Large (`lg`)
Generous breathing spacing ideal for hero sections or details views.
```tsx
<Card size="lg">...</Card>
```

## API Reference

### Card Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `variant` | `'default' \| 'flat' \| 'outline' \| 'glass'` | `'default'` | The visual style variation of the card. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Padding sizes applied to the card sections. |
| `divided` | `boolean` | `false` | When true, renders borders between header, body, and footer. |
| `elevation` | `0 \| 1 \| 2 \| 3 \| 'none' \| 'sm' \| 'md' \| 'lg'` | `1` | Shadow elevation level (applies to `'default'` variant only). |
