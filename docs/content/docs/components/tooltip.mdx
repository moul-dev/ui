The `Tooltip` component is built with React Aria and styled using StyleX.

## Import

```tsx
import { Tooltip } from '@moul-dev/ui';
```

## Usage

Here is a basic example of how to use the `Tooltip` component:

```tsx
import { Tooltip } from '@moul-dev/ui';

export default function Example() {
  return (
    <Tooltip>
      {/* Component content */}
    </Tooltip>
  );
}
```
