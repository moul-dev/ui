# ListBox

## Preview

<ComponentPlayground component="ListBox" />

A listbox displays a list of options and allows a user to select one or more of them. Built on React Aria Components and styled with StyleX.

## Import

```tsx
import {
  ListBox,
  ListBoxItem,
  ListBoxSection,
  ListBoxLoadMoreItem,
  DropIndicator,
  Text,
  Header,
} from '@moul-dev/ui';
```

## Basic Usage

A simple listbox allowing users to pick an option.

<ComponentPreview>

      <ListBoxItem id="cat">Cat</ListBoxItem>
      <ListBoxItem id="dog">Dog</ListBoxItem>
      <ListBoxItem id="kangaroo">Kangaroo</ListBoxItem>
      <ListBoxItem id="panda">Panda</ListBoxItem>

import { ListBox, ListBoxItem } from '@moul-dev/ui';

export default function Example() {
  return (

## Selection

Use `selectionMode="single"` or `selectionMode="multiple"` to control item selection. Use `showCheckmark` on items to display a clean checkmark indicator when selected.

<ComponentPreview>
  <ListBoxSelectionDemo />
</ComponentPreview>

```tsx
import { ListBox, ListBoxItem } from '@moul-dev/ui';
import { useState } from 'react';

export default function SelectionExample() {
  const [selected, setSelected] = useState(new Set(['cat', 'dog']));

  return (
    <div className="flex flex-col gap-2">
      <ListBox
        aria-label="Select pets"
        selectionMode="multiple"
        selectedKeys={selected}
        onSelectionChange={setSelected}
      >
        <ListBoxItem id="cat" showCheckmark>Cat</ListBoxItem>
        <ListBoxItem id="dog" showCheckmark>Dog</ListBoxItem>
        <ListBoxItem id="rabbit" showCheckmark>Rabbit</ListBoxItem>
        <ListBoxItem id="hamster" showCheckmark isDisabled>Hamster (Unavailable)</ListBoxItem>
      </ListBox>
      <p className="text-sm text-neutral-500">
        Selected: {Array.from(selected).join(', ') || 'None'}
      </p>
    </div>
  );
}
```

You can author labels and descriptions either via `label` and `description` props directly on `ListBoxItem`, or with `<Text slot="label">` and `<Text slot="description">` slots.

## Drag and Drop Reordering

ListBox integrates natively with React Aria's `useDragAndDrop` hook. Item reordering, dragging opacity, drop target outlines, and insertion line indicators (`DropIndicator`) are handled automatically.

<ComponentPreview>
  <ListBoxDndDemo />
</ComponentPreview>

```tsx
import { ListBox, ListBoxItem } from '@moul-dev/ui';
import { useDragAndDrop } from 'react-aria-components';
import { useState } from 'react';

export default function ReorderableList() {
  const [items, setItems] = useState([
    { id: '1', name: 'Lint and Format code' },
    { id: '2', name: 'Execute unit test suite' },
    { id: '3', name: 'Build production artifacts' },
    { id: '4', name: 'Deploy to edge network' },
  ]);

  const { dragAndDropHooks } = useDragAndDrop({
    getItems: (keys) =>
      Array.from(keys).map((key) => {
        const item = items.find((i) => i.id === key);
        return { 'text/plain': item?.name ?? String(key) };
      }),
    onReorder(e) {
      if (e.target.dropPosition === 'before') {
        const moving = items.filter((i) => e.keys.has(i.id));
        const remaining = items.filter((i) => !e.keys.has(i.id));
        const idx = remaining.findIndex((i) => i.id === e.target.key);
        const updated = [...remaining];
        updated.splice(idx, 0, ...moving);
        setItems(updated);
      } else if (e.target.dropPosition === 'after') {
        const moving = items.filter((i) => e.keys.has(i.id));
        const remaining = items.filter((i) => !e.keys.has(i.id));
        const idx = remaining.findIndex((i) => i.id === e.target.key);
        const updated = [...remaining];
        updated.splice(idx + 1, 0, ...moving);
        setItems(updated);
      }
    },
  });

  return (
    <ListBox
      aria-label="Reorderable deployment steps"
      selectionMode="single"
      dragAndDropHooks={dragAndDropHooks}
      items={items}
    >
      {(item) => <ListBoxItem id={item.id}>{item.name}</ListBoxItem>}
    </ListBox>
  );
}
```

## Asynchronous Loading

Use `renderEmptyState` for initial load states, and `ListBoxLoadMoreItem` for infinite scrolling lists. `ListBoxLoadMoreItem` renders `@moul-dev/ui`'s `Spinner` automatically when loading.

<ComponentPreview>
  <ListBoxAsyncDemo />
</ComponentPreview>

```tsx
import { ListBox, ListBoxItem, ListBoxLoadMoreItem, Spinner } from '@moul-dev/ui';

export default function AsyncLoadingExample() {
  return (
    <ListBox
      aria-label="Infinite feed"
      renderEmptyState={() => (
        <div className="flex justify-center p-4">
          <Spinner size="md" aria-label="Loading feed..." />
        </div>
      )}
    >
      <ListBoxItem id="post-1">First Post</ListBoxItem>
      <ListBoxItem id="post-2">Second Post</ListBoxItem>
      <ListBoxLoadMoreItem isLoading aria-label="Loading more posts..." />
    </ListBox>
  );
}
```
