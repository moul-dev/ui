Moul UI ផ្ដល់ជូននូវឯកសារ context កម្រិតស្តង់ដារសម្រាប់ម៉ាស៊ីន (Machine-readable context files) ដែលរៀបចំឡើងជាពិសេសសម្រាប់ LLMs និង AI coding assistants ដូចជា **Cursor**, **Windsurf**, **Claude Projects**, **GitHub Copilot**, **ChatGPT** និង **Antigravity**។

តាមរយៈការបញ្ចូលឯកសារ context ទាំងនេះទៅក្នុងប្រព័ន្ធ AI របស់អ្នក ម៉ូឌែលនឹងបង្កើតកូដ React Aria យ៉ាងត្រឹមត្រូវ គាំទ្រភាពងាយស្រួលប្រើប្រាស់ (Accessibility) នាំចូល compound components បានច្បាស់លាស់ និងអនុវត្តតាម token រចនារបស់ StyleX ដោយគ្មានបន្ទុក runtime និងមិនបង្កើត API ក្លែងក្លាយ (Hallucinated APIs) ឡើយ។

## គោលការណ៍គ្រឹះសម្រាប់ការបង្កើតកូដដោយ AI

នៅពេលបញ្ជាឱ្យ AI បង្កើតចំណុចប្រទាក់ជាមួយ Moul UI សូមប្រាប់ឱ្យម៉ូឌែលគោរពតាមគោលការណ៍សំខាន់ៗទាំងនេះ៖

<Accordions>
  <Accordion title="1. Event Handlers: onPress ជំនួសដោយ onClick">
    ប៊ូតុង និង action triggers របស់ Moul UI ដំណើរការដោយ React Aria ហើយប្រើប្រាស់ `onPress`៖
    
    ```tsx
    // ✅ ត្រឹមត្រូវ
    <Button variant="primary" onPress={() => handleSave()}>Save Changes</Button>

    // ❌ មិនត្រឹមត្រូវ
    <Button variant="primary" onClick={() => handleSave()}>Save Changes</Button>
    ```
  </Accordion>

  <Accordion title="2. រចនាសម្ព័ន្ធបែប Compound Components">
    សមាសភាគស្មុគស្មាញដូចជា `Modal`, `AlertDialog`, `Card`, `Tabs`, `Table`, `Select` និង `Sidebar` ប្រើប្រាស់អនុសមាសភាគ (Compound subcomponents) បែប declarative៖
    
    ```tsx
    // ✅ រចនាសម្ព័ន្ធ Modal ត្រឹមត្រូវ
    <ModalOverlay isOpen={isOpen} onOpenChange={setIsOpen}>
      <Modal size="md">
        <ModalDialog>
          <ModalHeader><h3>Title</h3></ModalHeader>
          <ModalBody><p>Body text</p></ModalBody>
          <ModalFooter><Button onPress={() => setIsOpen(false)}>Done</Button></ModalFooter>
        </ModalDialog>
      </Modal>
    </ModalOverlay>
    ```
  </Accordion>

  <Accordion title="3. ស្លាកសញ្ញាបញ្ជាក់ភាពងាយស្រួល (Accessible Labelling)">
    ប៊ូតុងដែលមានតែរូបតំណាង (Icon-only buttons) **ត្រូវតែ** រួមបញ្ចូល `aria-label`៖
    
    ```tsx
    // ✅ ងាយស្រួលប្រើប្រាស់ (Accessible)
    <Button variant="ghost" aria-label="Delete project" onPress={handleDelete}>
      <TrashIcon />
    </Button>
    ```
  </Accordion>

  <Accordion title="4. Design Tokens និងការកំណត់ Theme">
    ការកែសម្រួលរូបរាងម៉ាក អាចកំណត់បានតាមរយៈ CSS custom properties ឬ `<ThemeProvider>`៖
    
    ```css
    :root {
      --brand-hue: 250;               /* កម្រិតពណ៌ចម្បង Primary hue */
      --brand-chroma-multiplier: 1.0; /* កម្រិតឆ្អែតពណ៌ Saturation */
      --brand-radius-factor: 1.0;     /* កម្រិតមូលជ្រុង Corner roundness */
      --brand-density-factor: 1.0;    /* គម្លាត និងដង់ស៊ីតេ Spacing & density */
    }
    ```
  </Accordion>
</Accordions>

## គំរូ Prompts សម្រាប់ AI Assistants

ខាងក្រោមនេះជាទម្រង់ prompts ដែលអ្នកអាចចម្លងយកទៅប្រើប្រាស់ផ្ទាល់ជាមួយ AI assistant របស់អ្នក៖

<Steps>
  <Step>
    #### គំរូសម្រាប់ផ្ទាំងគ្រប់គ្រង Dashboard & Analytics
    
    ```text
    Create a responsive analytics dashboard using @moul-dev/ui.
    - Include Stat cards showing Revenue, Active Users, and Conversion Rate.
    - Add an AreaChart for monthly financial trends and a BarChart for traffic sources.
    - Include a recent transactions Table with selection and status Badges.
    - Follow @moul-dev/ui component imports and onPress handlers.
    ```
  </Step>

  <Step>
    #### គំរូសម្រាប់ទំព័រការកំណត់ Settings & Modal Form
    
    ```text
    Build a user settings page with @moul-dev/ui.
    - Include TextFields for Name and Email, a Select for Role, and a Switch for Two-Factor Authentication.
    - Add an "Invite Colleague" Button that opens a Modal with an email form and confirmation actions.
    - Dispatch a success notification using toastQueue.add() when changes are saved.
    ```
  </Step>
</Steps>
