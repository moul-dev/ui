# Select

The `<moul-select>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

## Import

```ts
import '@moul-dev/ui';
```

## HTML Usage

```html
<moul-select label="Role">
  <moul-select-item value="admin">Admin</moul-select-item>
</moul-select>
```
