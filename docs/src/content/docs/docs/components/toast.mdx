Toasts are queued with `toastQueue.add()`. They stack inside one `<moul-toast-region>` in the top layer, pause while hovered, and the remaining toasts glide together when one leaves.

## Placement

Set `toastQueue.placement` (or the `placement` attribute on `<moul-toast-region>`). Bottom regions stack upward, top regions stack downward.

## Usage

```js
import { toastQueue } from '@moul-dev/ui'

toastQueue.placement = 'top-center'
const id = toastQueue.add({
  title: 'Saved',
  description: 'Your settings were updated.',
  tone: 'success',   // primary | accent | success | warning | error
  variant: 'flat',   // default
  duration: 5000,    // 0 keeps it open
})
toastQueue.close(id)
```

## API reference

### `<moul-toast>`

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `tone` | `tone` | `'primary' \| 'accent' \| 'success' \| 'warning' \| 'error'` | `'primary'` |
| `variant` | `variant` | `'solid' \| 'flat' \| 'shadow' \| 'bordered' \| 'glass'` | `'flat'` |
| `duration` | `duration` | `number` | `5000` |
| `title` | `title` | `string` | `''` |
| `description` | `description` | `string` | `''` |
| `is-open` | `isOpen` | `boolean` | `true` |

| Event | Type |
| :-- | :-- |
| `dismiss` | `CustomEvent` |

| Slot | Description |
| :-- | :-- |
| `icon` | — |
| `title` | — |
| `(default)` | — |
| `action` | — |
