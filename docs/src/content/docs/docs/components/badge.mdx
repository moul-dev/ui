# Badge

The `<moul-badge>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

## Import

```ts
import '@moul-dev/ui';
```

## HTML Usage

```html
<moul-badge variant="success">Active</moul-badge>
```

| Name | Type | Default |
| :--- | :--- | :--- |
| `tone` | `SemanticTone` | `'primary'` |
| `variant` | `VisualVariant` | `'flat'` |
| `size` | `BadgeSize` | `'md'` |
| `is-dot` | `boolean` | `false` |
