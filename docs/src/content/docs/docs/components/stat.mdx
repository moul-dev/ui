# Stat

The `<moul-stat>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

## Preview

<ComponentPreview>
  <moul-stat title="Conversion Rate" value="4.8%" change="+0.6%"></moul-stat>
</ComponentPreview>

## Import

```ts
import '@moul-dev/ui';
```

## HTML Usage

```html
<moul-stat title="Visitors" value="10k"></moul-stat>
```
