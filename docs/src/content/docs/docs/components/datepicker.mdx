# DatePicker

The `<moul-date-picker>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

## Preview

<ComponentPreview>
  <moul-date-picker label="Scheduled Launch"></moul-date-picker>
</ComponentPreview>

## Import

```ts
import '@moul-dev/ui';
```

## HTML Usage

```html
<moul-date-picker label="Date"></moul-date-picker>
```
