`<moul-card>` groups related content. The `glass` variant is a liquid-glass panel that frosts whatever sits behind it.

## API reference

### `<moul-card>`

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `tone` | `tone` | `'primary' \| 'accent' \| 'success' \| 'warning' \| 'error'` | `'primary'` |
| `variant` | `variant` | `'solid' \| 'flat' \| 'shadow' \| 'bordered' \| 'glass'` | `'flat'` |
| `is-interactive` | `isInteractive` | `boolean` | `false` |

| Event | Type |
| :-- | :-- |
| `press` | `CustomEvent` |

| Slot | Description |
| :-- | :-- |
| `header` | — |
| `body` | — |
| `(default)` | — |
| `footer` | — |
