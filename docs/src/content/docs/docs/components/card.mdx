## Effects

`effect` adds light to a card, for landing pages and feature sections. It takes a space-separated list, so effects combine, and a name it does not know is ignored.

- `spotlight`: a soft light follows a mouse or pen across the card, under its content. It fades in when the pointer arrives and out where it leaves. A finger does not show it.
- `glare`: a band of light sweeps across the card once when the pointer arrives.
- `glow`: a gradient ring runs round the edge and a coloured glow sits outside the card, and both turn slowly. The glow pauses while the card is off screen.

### Colours and timing

Each effect has CSS properties for its colour, size and speed. The defaults come from the theme tokens, so they follow light and dark themes and your `--brand-hue`. A white band cannot show on a white card, so in the light theme the glare is a pale accent; in the dark theme, and on `solid` and `shadow` cards, it is white.

    <moul-card-header><strong>All checks passed</strong></moul-card-header>
    <moul-card-body>A glow in the success and teal chart colours, turning twice as fast.</moul-card-body>
  </moul-card>
  <moul-card effect="spotlight" style="width: 16rem; min-height: 9rem; --card-spotlight-size: 10rem; --card-spotlight-color: color-mix(in oklab, var(--color-chart-3) 30%, transparent)">
    <moul-card-header><strong>A smaller light</strong></moul-card-header>

```css
moul-card.status {
  --card-glow-color-1: var(--color-success);
  --card-glow-color-2: var(--color-chart-5);
  --card-glow-duration: 3s;
}

moul-card.feature {
  --card-spotlight-size: 10rem;
  --card-spotlight-color: color-mix(in oklab, var(--color-chart-3) 30%, transparent);
}
```

The glow lies outside the card, so leave room around it: a gap of about 2rem between glowing cards, and no clipping container right at its edge.

### Accessibility

The effect layers are empty and hidden from screen readers, so a card reads and behaves the same with or without them: an interactive card keeps its role, its name and its keys. The light is decoration, so keep text contrast checked against the card without it.

Under `prefers-reduced-motion: reduce` the spotlight shows and hides at once and rests at the centre instead of following the pointer, the glare is a still sheen across the middle while the card is hovered or focused, and the glow holds still. Where the system forces its own colours, as in Windows high contrast mode, and when printing, no effect is drawn.

## API reference

### `<moul-card>`

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `tone` | `tone` | `'primary' \| 'accent' \| 'success' \| 'warning' \| 'error'` | `'primary'` |
| `variant` | `variant` | `'solid' \| 'flat' \| 'shadow' \| 'bordered' \| 'glass'` | unset (neutral surface) |
| `is-interactive` | `isInteractive` | `boolean` | `false` |
| `effect` | `effect` | `string`: a space-separated list of `'spotlight'`, `'glare'` and `'glow'` | unset (no effect) |

| Event | Type |
| :-- | :-- |
| `press` | `CustomEvent` |

| Slot | Description |
| :-- | :-- |
| `header` | — |
| `body` | — |
| `(default)` | — |
| `footer` | — |

**CSS parts:** `header`, `body`, `content`, `footer`

| CSS property | Description | Default |
| :-- | :-- | :-- |
| `--card-spotlight-color` | The light at the centre of the `spotlight`. | the accent at 16% (light theme) or 28% (dark theme) |
| `--card-spotlight-size` | How far the `spotlight` reaches from the pointer, as a radius. | `20rem` |
| `--card-glare-color` | The band of the `glare`. | the accent at 14% (light theme), white at 14% (dark theme), white at 30% on `solid` and `shadow` cards |
| `--card-glare-duration` | How long the `glare` takes to cross. | `700ms` |
| `--card-glow-color-1` | The first `glow` colour. | `var(--color-accent)` |
| `--card-glow-color-2` | The second `glow` colour. | `var(--color-chart-4)` |
| `--card-glow-size` | The blur of the `glow` outside the card. | `1.5rem` |
| `--card-glow-width` | The width of the `glow` ring on the edge. | `1.5px` |
| `--card-glow-duration` | One turn of the `glow`. | `6s` |

The `CardEffect` type (`'spotlight' | 'glare' | 'glow'`) is exported for TypeScript.
