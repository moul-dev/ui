---
title: ToggleButton
description: A button that stays on or off.
---

import ComponentPreview from '@/components/ComponentPreview.astro';

`<moul-toggle-button>` keeps a pressed state. Selection tints the glass with the brand color and is announced through `aria-pressed`.

<div class="demo-row">
  <moul-toggle-button value="pin" is-selected>Pinned</moul-toggle-button>
  <moul-toggle-button value="star">Star</moul-toggle-button>
  <moul-toggle-button value="mute" size="sm">Mute</moul-toggle-button>
  <moul-toggle-button value="off" is-disabled>Disabled</moul-toggle-button>
</div>
</ComponentPreview>

## API reference

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `value` | `value` | `string` | `''` |
| `is-selected` | `isSelected` | `boolean` | `false` |
| `size` | `size` | `'sm' \| 'md' \| 'lg'` | `'md'` |
| `is-disabled` | `isDisabled` | `boolean` | `false` |

| Event | Type |
| :-- | :-- |
| `change` | `CustomEvent` |
| `press` | `CustomEvent` |

| Slot | Description |
| :-- | :-- |
| `(default)` | — |

**CSS parts:** `button`, `content`
