# Alert

The `<moul-alert>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

## Preview

<ComponentPreview>
  <moul-alert tone="primary" title="Information">Your deployment completed successfully.</moul-alert>
<moul-alert tone="danger" title="Error" style="margin-top: 0.75rem;">Failed to connect to database host.</moul-alert>
</ComponentPreview>

## Import

```ts
import '@moul-dev/ui';
```

## HTML Usage

```html
<moul-alert tone="primary" title="Information">
  Your deployment completed successfully.
</moul-alert>
```

## Attributes & Properties

| Name | Type | Default |
| :--- | :--- | :--- |
| `tone` | `SemanticTone` | `'primary'` |
| `variant` | `VisualVariant` | `'flat'` |
| `title` | `string` | `''` |
| `description` | `string` | `''` |
| `is-dismissible` | `boolean` | `false` |

## Events

| Event Name | Description |
| :--- | :--- |
| `dismiss` | Dispatched when element fires dismiss |
