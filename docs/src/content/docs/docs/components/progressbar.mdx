---
title: ProgressBar
description: Determinate or indeterminate progress.
---

import ComponentPreview from '@/components/ComponentPreview.astro';

`<moul-progress-bar>` glides its fill to each new `value`; `is-indeterminate` loops while the duration is unknown, and pulses instead of sweeping under reduced motion.

<ComponentPreview>
<div class="demo-stack" style="width: min(100%, 24rem)">
  <moul-progress-bar value="65"><span slot="label">Uploading assets</span></moul-progress-bar>
  <moul-progress-bar value="90" tone="success" size="sm"></moul-progress-bar>
  <moul-progress-bar value="35" tone="warning" shape="square" size="lg"></moul-progress-bar>
  <moul-progress-bar is-indeterminate><span slot="label">Preparing build</span></moul-progress-bar>
</div>
</ComponentPreview>

## API reference

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `value` | `value` | `number` | `0` |
| `min` | `min` | `number` | `0` |
| `max` | `max` | `number` | `100` |
| `tone` | `tone` | `'primary' \| 'accent' \| 'success' \| 'warning' \| 'error'` | `'primary'` |
| `variant` | `variant` | `'solid' \| 'flat' \| 'shadow' \| 'bordered' \| 'glass'` | `'solid'` |
| `size` | `size` | `'sm' \| 'md' \| 'lg'` | `'md'` |
| `shape` | `shape` | `'square' \| 'rounded' \| 'pill'` | `'pill'` |
| `is-indeterminate` | `isIndeterminate` | `boolean` | `false` |

| Slot | Description |
| :-- | :-- |
| `label` | — |

**CSS parts:** `fill`, `header`, `track`
