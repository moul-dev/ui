# ToggleButtonGroup

The `<moul-toggle-button-group>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

## Preview

<ComponentPreview>
  <moul-toggle-button-group>
  <moul-toggle-button value="bold" pressed>Bold</moul-toggle-button>
  <moul-toggle-button value="italic">Italic</moul-toggle-button>
  <moul-toggle-button value="underline">Underline</moul-toggle-button>
</moul-toggle-button-group>
</ComponentPreview>

## Import

```ts
import '@moul-dev/ui';
```

## HTML Usage

```html
<moul-toggle-button-group>
  <moul-toggle-button value="1">1</moul-toggle-button>
</moul-toggle-button-group>
```

| Name | Type | Default |
