# ButtonGroup

The `<moul-button-group>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

## Preview

<ComponentPreview>
  <moul-button-group>
  <moul-button variant="outline">Day</moul-button>
  <moul-button variant="outline">Week</moul-button>
  <moul-button variant="outline">Month</moul-button>
  <moul-button variant="outline">Year</moul-button>
</moul-button-group>
</ComponentPreview>

## Import

```ts
import '@moul-dev/ui';
```

## HTML Usage

```html
<moul-button-group>
  <moul-button variant="outline">Left</moul-button>
  <moul-button variant="outline">Right</moul-button>
</moul-button-group>
```

## Attributes & Properties

| Name | Type | Default |
| :--- | :--- | :--- |
| `orientation` | `ButtonGroupOrientation` | `'horizontal'` |
| `spacing` | `ButtonGroupSpacing` | `'sm'` |
| `is-disabled` | `boolean` | `false` |
