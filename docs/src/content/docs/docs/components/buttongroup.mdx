---
title: ButtonGroup
description: Visually joins related buttons into one control.
---

import ComponentPreview from '@/components/ComponentPreview.astro';

`<moul-button-group>` fuses adjacent buttons into a single shape. Use `spacing` to keep them apart while still grouping them for assistive technology.

## Attached

<ComponentPreview>
<moul-button-group spacing="none">
  <moul-button variant="secondary">Day</moul-button>
  <moul-button variant="secondary">Week</moul-button>
  <moul-button variant="secondary">Month</moul-button>
  <moul-button variant="secondary">Year</moul-button>
</moul-button-group>
</ComponentPreview>

```html
<moul-button-group spacing="none">
  <moul-button variant="secondary">Day</moul-button>
  <moul-button variant="secondary">Week</moul-button>
  <moul-button variant="secondary">Month</moul-button>
  <moul-button variant="secondary">Year</moul-button>
</moul-button-group>
```

## API reference

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `orientation` | `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` |
| `spacing` | `spacing` | `'none' \| 'sm' \| 'md'` | `'sm'` |
| `is-disabled` | `isDisabled` | `boolean` | `false` |

| Slot | Description |
| :-- | :-- |
| `(default)` | — |

**CSS parts:** `base`
