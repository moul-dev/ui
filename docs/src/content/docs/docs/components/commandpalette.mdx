`<moul-command-palette>` opens with ⌘K / Ctrl+K (change it with `shortcut`), filters `items` as you type and fires `select`.

<moul-button variant="secondary" data-open="demo-palette">Open palette <moul-kbd slot="suffix">⌘K</moul-kbd></moul-button>

</ComponentPreview>

```html
<moul-button variant="secondary">Open palette <moul-kbd slot="suffix">⌘K</moul-kbd></moul-button>
```

## API reference

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `is-open` | `isOpen` | `boolean` | `false` |
| `placeholder` | `placeholder` | `string` | `'Type a command or search...'` |
| `shortcut` | `shortcut` | `string` | `'k'` |
| `virtualized` | `virtualized` | `boolean` | `false` |
| `query` | `query` | `string` | `''` |
| `activeIndex` | `activeIndex` | `number` | `0` |

| Event | Type |
| :-- | :-- |
| `openchange` | `CustomEvent` |
| `select` | `CustomEvent` |

| Slot | Description |
| :-- | :-- |
| `header` | — |
| `empty` | — |
| `footer` | — |

**CSS parts:** `input`, `dialog`, `base`, `input-wrapper`, `list`, `empty`, `footer`
