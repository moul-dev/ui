`<moul-split-button>` pairs a main action with a chevron that opens a menu of related actions, drawn as one pill with a divider between the two parts. Use it when one action is the usual choice and its variants are rarer, such as "Deploy" with "Deploy to staging" behind the chevron. When no action stands out, use `<moul-dropdown-menu>` on its own.

## Usage

Put the main action's label in the default slot and its icon in the `prefix` slot. Menu items go on the split button itself with `slot="menu"`: `<moul-menu-item>`, `<moul-menu-group>` and `<moul-menu-separator>` all work, with the same keyboard navigation, type-ahead, checkbox and radio items as in a dropdown menu. Pressing the main part fires `press`; activating a menu item fires `action`. The chevron never fires `press`.

```html
  })
</script>
```

`menu-label` names the chevron and the menu for screen readers, since the chevron has no visible text. It defaults to "More actions".

## Variants

`variant` is forwarded to both parts and takes `primary` (the default), `secondary`, `tertiary`, `outline`, `ghost` or `danger`. Each draws a 1px divider between the parts that reads on its own fill: the foreground at 30% on `primary` and `danger`, at 15% on the neutral variants, and the border colour on `outline`. Any other value, `danger-soft` included, renders as `primary`. Set `--split-button-divider` to choose the divider colour yourself.

## Disabled and pending

`is-disabled` turns off both parts: neither can be focused or pressed, and the menu does not open, not even from `showMenu()`. `is-pending` applies to the main part only. It shows the button's pending loader, keeps the main part focusable with `aria-busy="true"`, and ignores presses, while the chevron and its menu stay usable, so the related actions remain reachable while the main one runs. Set `is-disabled` as well if the menu should wait too.

## Menu placement and width

The menu opens below the split button, aligned to the chevron's end edge (`placement="bottom-end"`), and flips above when there is no room below. `placement` also takes `bottom-start`, `top-start` and `top-end`. The menu is at least as wide as the whole split button, and never narrower than 10rem; style `::part(menu)` to change that. `showMenu()` opens it and focuses the first enabled item, and `hideMenu()` closes it.

## Accessibility

- There are two Tab stops, the main button and the chevron, each a native `<button>`. Screen readers hear two separate buttons: the split button itself has no role, and nothing ties the chevron to the main action except its name.
- The main button is named by its label. `Enter` and `Space` press it, and `Alt+Arrow Down` opens the menu and focuses its first enabled item.
- The chevron is named by `menu-label` (default "More actions") through visually hidden text, and has `aria-haspopup="menu"` and `aria-expanded`. A click toggles the menu; `Enter`, `Space` and `Arrow Down` open it on the first enabled item, and `Arrow Up` on the last. The menu surface is `role="menu"`, named by `menu-label` too.
- In the menu, the keys of `<moul-dropdown-menu>` apply: the arrow keys, `Home`, `End` and type-ahead. `Escape` or activating an item closes it and returns focus to the chevron; `Tab` closes it and lets focus move on.
- The chevron turns over while the menu is open. Under reduced motion it turns at once instead of rotating, and the menu appears without growing out of the chevron or staggering its items. Neither part scales down when pressed, so the pill never comes apart.

## API reference

### `<moul-split-button>`

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `variant` | `variant` | `'primary' \| 'secondary' \| 'tertiary' \| 'outline' \| 'ghost' \| 'danger'` | `'primary'` |
| `size` | `size` | `'sm' \| 'md' \| 'lg'` | `'md'` |
| `is-disabled` | `isDisabled` | `boolean` | `false` |
| `is-pending` | `isPending` | `boolean` | `false` |
| `menu-label` | `menuLabel` | `string` | `'More actions'` |
| `placement` | `placement` | `'bottom-start' \| 'bottom-end' \| 'top-start' \| 'top-end'` | `'bottom-end'` |

| Method | Description |
| :-- | :-- |
| `showMenu()` | Opens the menu and focuses its first enabled item; does nothing while disabled. |
| `hideMenu()` | Closes the menu, returning focus to the chevron if it was in the menu. |

| Event | Type |
| :-- | :-- |
| `press` | `CustomEvent<{ originalEvent: Event }>` (main part only) |
| `action` | `CustomEvent<{ value: string; item: MoulMenuItem }>` |
| `openchange` | `CustomEvent<{ isOpen: boolean }>` |

| Slot | Description |
| :-- | :-- |
| `(default)` | The main action's label. |
| `prefix` | An icon before the main action's label. |
| `menu` | The menu's items, groups and separators. |

| CSS custom property | Default |
| :-- | :-- |
| `--split-button-divider` | The variant's foreground at 30% (`primary`, `danger`) or 15% (`secondary`, `tertiary`, `ghost`); `var(--color-border)` on `outline` |

**CSS parts:** `main`, `trigger`, `chevron`, `menu`
