# ListBox

The `<moul-list-box>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

## Import

```ts
import '@moul-dev/ui';
```

```html

  <moul-list-box-item value="1">Item 1</moul-list-box-item>
</moul-list-box>
```
