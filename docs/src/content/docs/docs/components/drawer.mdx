# Drawer

The `<moul-drawer>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

## Preview

<ComponentPreview>
  <moul-button variant="outline">Open Settings Drawer</moul-button>
</ComponentPreview>

## Import

```ts
import '@moul-dev/ui';
```

## HTML Usage

```html
<moul-drawer placement="right" title="Drawer Title">
  <p>Drawer content</p>
</moul-drawer>
```

## Attributes & Properties

| Name | Type | Default |
| :--- | :--- | :--- |
| `is-open` | `boolean` | `false` |
| `placement` | `DrawerPlacement` | `'right'` |
| `size` | `DrawerSize` | `'md'` |
| `is-dismissable` | `boolean` | `true` |

| Event Name | Description |
| :--- | :--- |
| `openchange` | Dispatched when element fires openchange |
