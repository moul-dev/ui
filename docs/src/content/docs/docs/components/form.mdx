# Form

The `<moul-form>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

## Preview

<ComponentPreview>
  <moul-form style="width: 100%; max-width: 360px;">
  <moul-text-field label="Username" placeholder="alice" required></moul-text-field>
  <div style="margin-top: 1rem;">
    <moul-button type="submit" variant="primary">Submit</moul-button>
  </div>
</moul-form>
</ComponentPreview>

## Import

```ts
import '@moul-dev/ui';
```

## HTML Usage

```html
<moul-form>
  <moul-text-field label="Name" required></moul-text-field>
  <moul-button type="submit">Submit</moul-button>
</moul-form>
```

## Attributes & Properties

| Name | Type | Default |
| :--- | :--- | :--- |
| `action` | `string` | `''` |
| `method` | `FormMethod` | `'post'` |
| `novalidate` | `boolean` | `false` |
