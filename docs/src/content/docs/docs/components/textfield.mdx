# TextField

The `<moul-text-field>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

## Preview

<ComponentPreview>
  <moul-text-field label="Application Name" placeholder="moul-portal" description="Unique alphanumeric identifier." style="width: 100%; max-width: 360px;"></moul-text-field>
</ComponentPreview>

## Import

```ts
import '@moul-dev/ui';
```

## HTML Usage

```html
<moul-text-field label="Name" placeholder="Enter name..."></moul-text-field>
```
