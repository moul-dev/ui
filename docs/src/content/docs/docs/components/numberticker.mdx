`<moul-number-ticker>` shows a number and animates to each new `value`. By default it rolls like an odometer: each digit slides up when the number grows and down when it shrinks, a new leading digit slides in, and one that is dropped leaves. Separators, signs and currency symbols stay put.

The ticker takes its size, weight, colour and line height from the text around it, and sets its digits in tabular figures so the number does not change width as it rolls. Setting a new `value` mid-roll is safe: each digit carries on from where it is.

## Count mode

`mode="count"` springs the whole number through the values in between instead, the way a scoreboard counts up. Values in between keep the final value's fraction digits, so `40.25` never flickers through `40.2531`.

## Formatting

The number is formatted with [`Intl.NumberFormat`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/NumberFormat). Set `locale` and pass options as the `formatOptions` property for currency, percentages, compact notation or fixed fraction digits. Digits in another numbering system roll too: `numberingSystem: 'khmr'` rolls Khmer numerals.

```js
const price = document.querySelector('#price')
price.locale = 'en-US'
price.formatOptions = { style: 'currency', currency: 'USD' }
price.value = 1249.9
```

```js
const year = document.querySelector('#year')
year.locale = 'km'
year.formatOptions = { numberingSystem: 'khmr', useGrouping: false }
year.value = 2026
```

For text that is not part of the format, such as a unit, use the `prefix` and `suffix` slots.

```html
<moul-number-ticker value="12">
  <span slot="suffix">&nbsp;GB</span>
</moul-number-ticker>
```

## Counting up on view

Set `from` and the ticker shows that number until it first scrolls into view, then animates to `value`. It is the stats-band effect: numbers that count up as the reader reaches them.

## Accessibility

The moving digits are hidden from screen readers. A visually hidden copy of the final, formatted value is read in their place, so a screen reader never reads `1,2,8` on its way to `1,530`. The ticker is not a live region: a changed value is not announced. To announce it, put the ticker in an element with `aria-live="polite"`.

Under reduced motion the number jumps to each new value, and `from` is ignored.

## API reference

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `value` | `value` | `number` | `0` |
| `mode` | `mode` | `'roll' \| 'count'` | `'roll'` |
| `from` | `from` | `number \| undefined` | `undefined` |
| `locale` | `locale` | `string \| undefined` | the browser's |
| — | `formatOptions` | `Intl.NumberFormatOptions \| undefined` | `undefined` |

| Slot | Description |
| :-- | :-- |
| `prefix` | Content before the number. |
| `suffix` | Content after the number, such as a unit. |

**CSS parts:** `digits` (the visible number), `digit` (each rolling digit), `symbol` (each static character).
