# Switch

The `<moul-switch>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

## Preview

<ComponentPreview>
  <div style="display: flex; flex-direction: column; gap: 0.75rem;">
  <moul-switch checked>Auto-deploy on git push</moul-switch>
  <moul-switch>Enable debug logging</moul-switch>
</div>
</ComponentPreview>

## Import

```ts
import '@moul-dev/ui';
```

## HTML Usage

```html
<moul-switch checked>Enable notifications</moul-switch>
```

## Attributes & Properties

| Name | Type | Default |
| :--- | :--- | :--- |
| `name` | `string` | `''` |
| `value` | `string` | `'on'` |
| `is-checked` | `boolean` | `false` |
| `is-disabled` | `boolean` | `false` |
| `label` | `string` | `''` |
| `size` | `SwitchSize` | `'md'` |

## Events

| Event Name | Description |
| :--- | :--- |
| `change` | Dispatched when element fires change |
