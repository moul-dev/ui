import ComponentPreview from '@/components/ComponentPreview.astro';

`<moul-button>` triggers an action. It springs down on press, exposes a pending state that keeps its width, and fires a `press` event for pointer and keyboard activation alike.

## States

Pending buttons show a spinner and ignore presses; disabled buttons are skipped by focus.

## API reference

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `variant` | `variant` | `'primary' \| 'secondary' \| 'tertiary' \| 'outline' \| 'ghost' \| 'danger' \| 'danger-soft'` | `'primary'` |
| `size` | `size` | `'sm' \| 'md' \| 'lg'` | `'md'` |
| `type` | `type` | `'button' \| 'submit' \| 'reset'` | `'button'` |
| `is-icon` | `isIcon` | `boolean` | `false` |
| `is-disabled` | `isDisabled` | `boolean` | `false` |
| `is-pending` | `isPending` | `boolean` | `false` |

| Event | Type |
| :-- | :-- |
| `press` | `CustomEvent` |

| Slot | Description |
| :-- | :-- |
| `prefix` | — |
| `(default)` | — |
| `suffix` | — |

**CSS parts:** `button`, `spinner`, `prefix`, `content`, `suffix`
