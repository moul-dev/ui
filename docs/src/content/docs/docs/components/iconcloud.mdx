`<moul-icon-cloud>` spreads icons or logos evenly over a sphere and turns it slowly. Icons at the front are full size, icons at the back smaller and faded. The sphere leans toward the pointer and spins when you drag it. Use it for a "works with" or "built with" section, where the point is how many things there are rather than any one of them.

Each icon in the demo is a link to that component's page: press one, or press Tab to move through them.

It lives in the canvas entry, which loads its file the first time the tag appears on the page:

```js
import '@moul-dev/web-component/canvas'
// or register just this element, straight away:
import '@moul-dev/web-component/canvas/icon-cloud'
```

```html
<moul-icon-cloud label="Integrations">
  <a href="/integrations/github"><img src="/logos/github.svg" alt="GitHub" /></a>
  <a href="/integrations/slack"><img src="/logos/slack.svg" alt="Slack" /></a>
  <img src="/logos/stripe.svg" alt="Stripe" />
</moul-icon-cloud>
```

## Icons

Every child is one icon, placed on the sphere in order. A child can be:

- an `<img>`, drawn as it is, colours and all;
- an inline `<svg>`, drawn at the icon size. One drawn in `currentColor` takes `--icon-cloud-icon-color`, the foreground by default, so a set of monochrome icons follows the theme;
- a link or a button wrapping either of those;
- anything else with text, drawn as a round chip with its first two letters.

Each icon is drawn once into a picture of its own, at the screen's density, and every frame only places those pictures, so the cloud stays smooth with a few dozen icons. Fifteen to forty reads best: fewer leaves gaps, and more crowds the front. An inline SVG is drawn as an image, so it cannot see the page's CSS: give it its colours as attributes or `currentColor`, not `var()`. Images from another origin draw fine; nothing is read back from the canvas.

## Motion

The sphere turns `speed` degrees a second on its own (14 by default) and leans toward a mouse or pen over it, faster the nearer the edge. Drag it with a mouse, a pen or a finger to spin it; let go mid-drag and it carries on, then settles back into its own turn. On a touch screen a mostly vertical swipe still scrolls the page (`touch-action: pan-y`). `is-paused` stops the turn and the lean; dragging still works. The canvas stops drawing while the cloud is off screen or the tab is hidden.

## Pressing an icon

A press that does not drag fires `press` with the icon's element and index in `detail`. If the icon is a link or a button, or holds one, it is then activated, as a click on it would be. Cancel the event to handle the press yourself:

```js
cloud.addEventListener('press', (event) => {
  event.preventDefault()
  showDetails(event.detail.index)
})
```

The pointer turns into a hand over icons that can be pressed.

## Size

The cloud is square and fills its container's width; give it a `max-width`, a `height` or another `aspect-ratio` to change that. The sphere fills the box unless `radius` sets it in CSS pixels. `icon-size` is the width of an icon at the front (40 by default); at the back an icon is half that.

## Accessibility

The children stay in the page, out of sight, in a group named by `label`. A screen reader reads each image's alt text and each link's name in order, so give every `<img>` an `alt` and every icon-only link an `aria-label`. The canvas is hidden from assistive technology.

Links and buttons stay in the tab order. Focusing one turns the sphere to bring its icon to the front, rings it in `--icon-cloud-focus-color` (the focus colour) and holds the sphere still while focus stays inside. Enter follows a link as it always does.

Under `prefers-reduced-motion: reduce` the sphere does not turn on its own or lean toward the pointer. Dragging still turns it, since the reader's own hand moves it, but it stops when let go, and focusing an icon brings it to the front at once.

## Attributes and properties

| Attribute | Property | Type | Default | Description |
| :-- | :-- | :-- | :-- | :-- |
| `label` | `label` | `string` | `''` | Accessible name of the group of icons. |
| `radius` | `radius` | `number` | fills the box | Radius of the sphere in CSS pixels. |
| `speed` | `speed` | `number` | `14` | How fast the sphere turns on its own, in degrees a second. |
| `icon-size` | `iconSize` | `number` | `40` | Width of an icon at the front, in CSS pixels. |
| `is-paused` | `isPaused` | `boolean` | `false` | Stop turning on its own and leaning toward the pointer. |
| | `icons` | `Element[]` | | The slotted icons, in order (read only). |
| | `focusedIndex` | `number` | `-1` | Index of the icon whose link or button has focus (read only). |

## Events

| Event | Detail | Description |
| :-- | :-- | :-- |
| `press` | `{ item: Element, index: number }` | An icon was pressed without dragging. Cancelable: cancel it to stop a link or button inside from being activated. |

## CSS parts and custom properties

| Part | Description |
| :-- | :-- |
| `base` | The box that holds the canvas. |
| `canvas` | The canvas the icons are drawn on. |
| `items` | The visually hidden group that holds the slotted icons. |

| Property | Default | Description |
| :-- | :-- | :-- |
| `--icon-cloud-icon-color` | `var(--color-fg)` | Colour for monochrome SVGs drawn in `currentColor`, and for the letters on text chips. |
| `--icon-cloud-focus-color` | `var(--color-focus)` | The ring round the focused icon. |
