`<moul-tree>` shows nested `<moul-tree-item>` elements as a collapsible tree. Branches open with a spring, guide lines branch from each parent to its children, and the whole tree is one tab stop driven by the arrow keys, as the WAI-ARIA tree view pattern describes.

## Single selection

Nest items in light DOM. Each item needs a `value` (what `selectedKeys` and the events report) and a `label`. `is-expanded` opens a branch, `is-selected` selects an item, and `is-disabled` keeps an item from being selected or activated.

## Multiple selection

With `selection-mode="multiple"`, a click or `Space` toggles an item in and out of the selection. Set `selectedKeys` to select from code; that does not fire `selectionchange`.

## Activation and navigation

`action` fires when an item is activated: with `Enter`, with a click on its row when `selection-mode="none"`, or with a double-click in the other modes (where a single click selects). Activating a branch also opens or closes it; call `preventDefault()` on the event to stop that. With `none`, nothing is ever selected, so the tree works as nested navigation. Disabled items are never activated.

## Loading children later

`has-children` marks a branch whose children are not there yet: it shows the chevron, and opening it fires `expandedchange` with the item, so you can fetch and append its children. Levels, positions and names are set on whatever you append.

```html
<moul-tree label="Remote files">
  <moul-tree-item value="/var" label="var" has-children></moul-tree-item>
</moul-tree>
```

```js
tree.addEventListener('expandedchange', async (event) => {
  const { value, isExpanded, item } = event.detail
  if (!isExpanded || item.childElementCount > 0) return
  const entries = await listDirectory(value)
  for (const entry of entries) {
    const child = document.createElement('moul-tree-item')
    child.value = entry.path
    child.label = entry.name
    child.hasChildren = entry.isDirectory
    item.append(child)
  }
})
```

## Icons and rich labels

`slot="prefix"` holds an icon, `slot="suffix"` holds meta such as a count, and `slot="label"` replaces the plain `label` with markup. The item's accessible name comes from `label` when it is set, else from the label slot's text, never from its children or its suffix.

```html
<moul-tree-item value="inbox" label="Inbox, 12 unread">
  <svg slot="prefix" aria-hidden="true"><!-- icon --></svg>
  <span slot="label"><strong>Inbox</strong></span>
  <moul-badge slot="suffix" size="sm">12</moul-badge>
</moul-tree-item>
```

## Keyboard

| Key | Action |
| :-- | :-- |
| `Arrow Down` / `Arrow Up` | Next or previous visible item (no wrapping) |
| `Arrow Right` | Opens a closed branch; on an open one, moves to its first child |
| `Arrow Left` | Closes an open branch; otherwise moves to the parent |
| `Home` / `End` | First or last visible item |
| `Enter` | Activates the item (`action`), and selects it in single mode |
| `Space` | Selects the item in single mode, toggles it in multiple mode |
| `*` | Opens every sibling branch |
| Letters | Moves to the next item whose label starts with the typed text |

`Arrow Left` and `Arrow Right` swap under `dir="rtl"`. Disabled items can be focused and opened, but never selected or activated.

## Styling

`--moul-tree-indent` sets how far each level steps in (default `1.5rem`), and `--moul-tree-guide-color` colours the guide lines (default `var(--color-border)`; `transparent` hides them). Rows are reachable as `moul-tree-item::part(row)`.

```css
moul-tree {
  --moul-tree-indent: 1.25rem;
  --moul-tree-guide-color: var(--color-border-subtle);
}
```

## API reference

### `<moul-tree>`

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `selection-mode` | `selectionMode` | `'none' \| 'single' \| 'multiple'` | `'single'` |
| — | `selectedKeys` | `string[]` | `[]` |
| `label` | `label` | `string` | `''` |

| Event | Type |
| :-- | :-- |
| `selectionchange` | `CustomEvent<{ selectedKeys: string[] }>` |
| `expandedchange` | `CustomEvent<{ value: string, isExpanded: boolean, item: MoulTreeItem }>` |
| `action` | `CustomEvent<{ value: string, item: MoulTreeItem }>` (cancelable) |

| Slot | Description |
| :-- | :-- |
| `(default)` | Top-level `<moul-tree-item>` elements |

| CSS custom property | Default |
| :-- | :-- |
| `--moul-tree-indent` | `1.5rem` |
| `--moul-tree-guide-color` | `var(--color-border)` |

### `<moul-tree-item>`

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `value` | `value` | `string` | `''` |
| `label` | `label` | `string` | `''` |
| `is-expanded` | `isExpanded` | `boolean` | `false` |
| `is-selected` | `isSelected` | `boolean` | `false` |
| `is-disabled` | `isDisabled` | `boolean` | `false` |
| `has-children` | `hasChildren` | `boolean` | `false` |
| — | `isBranch` (read-only) | `boolean` | — |

| Slot | Description |
| :-- | :-- |
| `(default)` | Nested `<moul-tree-item>` children (direct children only) |
| `label` | Rich label, shown instead of `label` |
| `prefix` | Icon before the label |
| `suffix` | Non-interactive meta after the label |

**CSS parts:** `row`, `toggle`, `label`, `guide`, `group`
