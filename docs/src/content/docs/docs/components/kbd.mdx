# Kbd

The `<moul-kbd>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

## Preview

</ComponentPreview>

## Import

```ts
import '@moul-dev/ui';
```

## HTML Usage

```html
<moul-kbd>⌘</moul-kbd> <moul-kbd>K</moul-kbd>
```
