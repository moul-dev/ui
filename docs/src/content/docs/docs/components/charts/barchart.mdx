# BarChart

The `<moul-bar-chart>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

## Preview

<ComponentPreview>
  <moul-bar-chart height="220" style="width: 100%;"></moul-bar-chart>
</ComponentPreview>

## Import

```ts
import '@moul-dev/ui';
```

## HTML Usage

```html
<moul-bar-chart height="300"></moul-bar-chart>
```

## Attributes & Properties

| Name | Type | Default |
| :--- | :--- | :--- |
| `x-key` | `string` | `'name'` |
| `height` | `number` | `300` |
| `layout` | `'vertical' | 'horizontal'` | `'vertical'` |
| `stacked` | `boolean` | `false` |
| `show-grid` | `boolean` | `true` |
