Scrubbing works as it does on `<moul-area-chart>`: `point-hover` carries the series nearest the pointer plus `index` and every series' value in `entries`, ready for a `<moul-chart-tooltip>`. Set `scrub="false"` for a chart that only reacts to its dots.

## Live

`is-live` turns the chart into a real-time feed. `push()` appends a reading, or an array of them, and `max-points` keeps only the latest ones. The newest reading sits at the right edge with a pulsing dot, and the line glides left to make room for each new one, over the time since the previous push (at most a second), so a steady feed scrolls without stopping. Live charts draw no dot on every point; scrub to read a value.

The pause button in the corner freezes the view while readings keep arriving; resuming jumps to the latest. Scrubbing holds the view still too, so the value under the guide does not slide away.


```js
const chart = document.querySelector('moul-line-chart')
chart.series = [
  { key: 'cpu', name: 'CPU' },
  { key: 'memory', name: 'Memory' },
]
chart.valueFormatter = (value) => `${value}%`

const source = new EventSource('/metrics')
source.onmessage = (event) => chart.push(JSON.parse(event.data))

chart.addEventListener('pausechange', (event) => {
  console.log(event.detail.isPaused ? 'paused' : 'live')
})
```

`data` always holds the latest readings, paused or not. `is-paused` freezes only what is drawn, so the app can pause from its own controls by setting it; only the built-in button fires `pausechange`. The line glides once `max-points` is set, since the gap between readings depends on it. Labels along the bottom thin out to one every few readings and glide with the line.

`push()` works without `is-live` too: it appends and trims, and the chart redraws without gliding.

## Accessibility

- With scrubbing on, the plot is one tab stop exposed as a `role="slider"` named by `label` ("Line chart" when unset). Keyboard focus shows the latest category; `Arrow` keys step, `Home` and `End` jump, and `Escape` or leaving focus hides the guide.
- `aria-valuetext` reads the category and every value through `valueFormatter`, for example "10:42:07: CPU 61%, Memory 48%".
- In live mode the pause button follows the plot in tab order. It is a native button named "Pause live updates" with `aria-pressed`, toggled by `Enter` or `Space`. New readings are not announced.
- With `scrub="false"` nothing in the plot takes focus, and the SVG is one `role="img"` named by `label`; give the page a table or text alternative.
- Under reduced motion the lines appear without fading in, a live line jumps to each reading instead of gliding, the newest dot does not pulse, and the guide moves without gliding.

## API reference

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `x-key` | `xKey` | `string` | `'name'` |
| `height` | `height` | `number` | `300` |
| `show-grid` | `showGrid` | `boolean` | `true` |
| `curve` | `curve` | `string` | `'monotoneX'` |
| `scrub` | `scrub` | `boolean` (`scrub="false"` turns it off) | `true` |
| `label` | `label` | `string` | `''` (read as "Line chart") |
| `is-live` | `isLive` | `boolean` | `false` |
| `is-paused` | `isPaused` | `boolean` | `false` |
| `max-points` | `maxPoints` | `number` | `0` (keep every reading) |
| | `data` | `Record<string, unknown>[]` | `[]` |
| | `series` | `ChartSeries[]` | `[]` (every numeric field) |
| | `valueFormatter` | `(value) => string` | |

| Method | Description |
| :-- | :-- |
| `push(row \| rows)` | Appends readings, keeps the latest `max-points`, and glides a live chart left. |

| Event | Detail |
| :-- | :-- |
| `point-hover` | `{ point, series, value, label, x, y, index, entries }`; `index` and `entries` come with scrubbing |
| `point-leave` | none |
| `pausechange` | `{ isPaused }`, from the built-in pause button |

| Slot | Description |
| :-- | :-- |
| `empty` | Shown instead of the chart when there is no data. |

**CSS parts:** `empty`, `container`, `grid`, `line`, `point`, `track`, `head`, `pause-button`, `scrub-guide`, `scrub-dot`
