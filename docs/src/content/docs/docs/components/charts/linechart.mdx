# LineChart

The `<moul-line-chart>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

## Preview

<ComponentPreview>
  <moul-line-chart height="220" style="width: 100%;"></moul-line-chart>
</ComponentPreview>

## Import

```ts
import '@moul-dev/ui';
```

## HTML Usage

```html
<moul-line-chart height="300"></moul-line-chart>
```

## Attributes & Properties

| Name | Type | Default |
| :--- | :--- | :--- |
| `x-key` | `string` | `'name'` |
| `height` | `number` | `300` |
| `show-grid` | `boolean` | `true` |
| `curve` | `string` | `'monotoneX'` |

## Events

| Event Name | Description |
| :--- | :--- |
| `point-hover` | Dispatched when element fires point-hover |
| `point-leave` | Dispatched when element fires point-leave |
