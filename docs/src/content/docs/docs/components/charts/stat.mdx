`<moul-stat>` counts up to `value` with a spring and shows the trend beside it.

<ComponentPreview>
<div class="demo-row" style="align-items: stretch">
  <moul-stat label="Revenue" value="52400" prefix="$" trend="up" trend-value="+14.8%" description="vs last month" tone="success"></moul-stat>
  <moul-stat label="Error rate" value="0.42" suffix="%" trend="down" trend-value="-0.1%" description="last 24h" variant="glass"></moul-stat>
</div>
</ComponentPreview>
