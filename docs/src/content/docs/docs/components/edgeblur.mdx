`<moul-edge-blur>` is a scroll container whose content blurs out toward its edges, so a list or a column of text fades softly into the page instead of stopping at a hard line. The blur is not one flat layer: it ramps up across a band at each edge, light on the inside and strongest at the very edge.

The element is the scroller itself, so it needs a limit: give it a `height` or a `max-height`, or let a grid or flex parent size it.

Pad the content, not the element. Padding on `<moul-edge-blur>` sits outside the blurred bands, so the blur would stop short of the edge; put it on your own wrapper, as above, or on `::part(content)`.

## Scrolling and the blur

Where the browser has scroll-driven animations, each edge blurs only while there is more to scroll that way. At the top the first line is sharp and the bottom edge is blurred; scroll down and the top edge blurs in over the band's length; reach the end and the bottom edge clears. Content that fits, with nothing to scroll, shows no blur at all. Nothing runs between scrolls: the browser ties the fade to the scroll position.

Browsers without scroll-driven animations show both edges all the time. There, the element pads its content by the band's length at each blurred edge, so the first and last lines can still be scrolled clear of the blur.

## Orientation

`orientation="horizontal"` makes a row that scrolls sideways and blurs its inline start and end. Each child is one item in the row, `var(--spacing-4)` apart; change the spacing with `--edge-blur-gap`. In right-to-left text the start is on the right, and the blur follows it.

## Edges

`edges` picks which edges blur: `both` (the default), `start` (the top, or the inline start in a row) or `end` (the bottom, or the inline end). A feed that always opens at the top often needs only the end.

## Band and strength

`--edge-blur-size` is the length of each blurred band, `4rem` by default. `--edge-blur-strength` is the blur at the very edge, `8px` by default; four layers step up to it, each twice as strong as the one before, so the blur ramps up across the band.

Blur alone keeps the content's colour, so the edge reads as frosted rather than faded. `--edge-blur-fade-color` also fades the content into a colour toward the edge: set it to the surface behind the element, such as `var(--color-surface)` on a card, and the content melts into it. It is `transparent` by default, which leaves the blur alone, because the element cannot know what lies behind it.

```css
}
```

Every layer is a `backdrop-filter`, which the browser redraws as the content moves under it. Keep the strength modest and avoid many edge blurs on one screen, especially on low-powered phones.

## Accessibility

`<moul-edge-blur>` joins the tab order with `tabindex="0"`, so a keyboard user can reach it and scroll it with the arrow keys, Page Up, Page Down, Home and End, and it shows a focus ring while focused from the keyboard. A `tabindex` you set yourself is kept: set `tabindex="-1"` if the content never overflows and the extra tab stop would only get in the way.

Give it a name with `aria-label` or `aria-labelledby`. Once named it takes `role="region"`, so screen readers announce what it holds and can list it among the page's landmarks; a role you set yourself is kept. Without a name it adds no role.

The blur layers are `aria-hidden` and ignore the pointer, so the content under them can still be read, clicked and selected. The element sets `scroll-padding` to the band's length at each blurred edge, so a link or a button that takes focus inside it, or anything you bring in with `scrollIntoView()`, is scrolled clear of the blur rather than left underneath it.

Where the system forces its own colours, as in Windows high contrast mode, and when printing, the blur is removed and the content shows plain.

Under `prefers-reduced-motion: reduce` nothing changes: the element moves nothing on its own, and the fade of each edge follows only the reader's own scrolling.

## Attributes and properties

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `orientation` | `orientation` | `'vertical' \| 'horizontal'` | `'vertical'` |
| `edges` | `edges` | `'both' \| 'start' \| 'end'` | `'both'` |

| Slot | Description |
| :-- | :-- |
| (default) | The content to scroll. In horizontal mode each child is one item in the row. |

| Part | Description |
| :-- | :-- |
| `content` | The wrapper around the content. Pad the content here, not on the element. |
| `edge` | Each blurred band. |
| `edge-start` | The band at the top, or at the inline start in a row. |
| `edge-end` | The band at the bottom, or at the inline end in a row. |

| CSS property | Description | Default |
| :-- | :-- | :-- |
| `--edge-blur-size` | The length of each blurred band. | `4rem` |
| `--edge-blur-strength` | The blur at the very edge. | `8px` |
| `--edge-blur-fade-color` | A colour the content also fades into toward the edge. | `transparent` |
| `--edge-blur-gap` | Space between the items in a horizontal row. | `var(--spacing-4)` |
