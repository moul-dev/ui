title: Breadcrumbs

import ComponentPreview from '@/components/ComponentPreview.astro';

`<moul-breadcrumbs>` renders a navigation landmark; the `is-current` item gets `aria-current="page"`.

<ComponentPreview>
<moul-breadcrumbs>
  <moul-breadcrumb-item href="#">Home</moul-breadcrumb-item>
  <moul-breadcrumb-item href="#">Projects</moul-breadcrumb-item>
  <moul-breadcrumb-item href="#">moul-portal</moul-breadcrumb-item>
  <moul-breadcrumb-item is-current>Settings</moul-breadcrumb-item>
</moul-breadcrumbs>
</ComponentPreview>

```html
<moul-breadcrumbs>
  <moul-breadcrumb-item href="#">Home</moul-breadcrumb-item>
  <moul-breadcrumb-item href="#">Projects</moul-breadcrumb-item>
  <moul-breadcrumb-item href="#">moul-portal</moul-breadcrumb-item>
  <moul-breadcrumb-item is-current>Settings</moul-breadcrumb-item>
</moul-breadcrumbs>
```

## API reference

### `<moul-breadcrumbs>`

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `separator` | `separator` | `string` | `'/'` |

| Slot | Description |
| :-- | :-- |
| `(default)` | — |

**CSS parts:** `base`, `list`

### `<moul-breadcrumb-item>`

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `href` | `href` | `string` | `''` |
| `is-current` | `isCurrent` | `boolean` | `false` |
| `separator` | `separator` | `string` | `''` |

| Slot | Description |
| :-- | :-- |
| `(default)` | — |
| `separator` | — |

**CSS parts:** `item`, `link`, `text`, `separator`
