```js
import '@moul-dev/web-component/effects'
```

```html
<moul-orbit show-path>
  <img src="/logos/brightloom.svg" alt="Brightloom" />
  <img src="/logos/tidewell.svg" alt="Tidewell" />
  <img src="/logos/cobaltine.svg" alt="Cobaltine" />
  <img slot="center" src="/logo.svg" alt="Moul" width="56" height="56" />
</moul-orbit>
```

Make each item an element, such as an `<img>`, an `<svg>`, a `<span>` or a `moul-avatar`. The first item sits at the top and the rest follow clockwise, evenly spaced; the orbit spaces them again whenever you add or remove one. Text placed directly in the orbit, outside an element, is not put on the ring.

## Radius and item size

`radius` is the distance from the centre to the middle of each item, in pixels, 120 by default. Every item is sized to `--orbit-item-size`, `2.5rem` by default, and images keep their shape inside that box. The orbit is a square twice the radius plus one item across, so the items at its edges stay inside it.

An item's own width and height from your page's CSS win over `--orbit-item-size`, and the orbit still centres it on the ring.

## Speed and direction

`duration` is the number of seconds one full turn takes, 20 by default; a larger number turns more slowly. The ring turns clockwise; `is-reverse` turns it anticlockwise. In right-to-left text the orbit is mirrored: the items run anticlockwise from the top and the ring turns that way, and `is-reverse` turns it clockwise.

```html
<moul-orbit duration="40">…</moul-orbit>
<moul-orbit is-reverse>…</moul-orbit>
```

## Path

`show-path` draws the ring as a faint circle through the middle of the items. Its colour is `--orbit-path-color`, `var(--color-border)` by default; style it further, for a dashed line, through `::part(path)`.

```css
moul-orbit {
  --orbit-path-color: var(--color-accent-soft);
}

moul-orbit::part(path) {
  border-style: dashed;
}
```

## Rings

For a second ring, put another `moul-orbit` in the centre slot. Each orbit has its own `radius`, `duration` and direction, and its own centre slot, which can hold a third orbit or the content for the very middle. Give the inner orbit a smaller radius so its items clear the outer ring's.

```html
<moul-orbit radius="128" show-path>
  <img src="/logos/brightloom.svg" alt="Brightloom" />
  <img src="/logos/tidewell.svg" alt="Tidewell" />
  <moul-orbit slot="center" radius="64" duration="14" is-reverse show-path>
    <img src="/logos/ashgrove.svg" alt="Ashgrove" />
    <img src="/logos/marlpeak.svg" alt="Marlpeak" />
    <img slot="center" src="/logo.svg" alt="Moul" width="52" height="52" />
  </moul-orbit>
</moul-orbit>
```

## Pausing

`pause-on-hover` holds the orbit still while the pointer is over it, which helps a reader who wants to click an item. The orbit also pauses on its own while focus is inside it and while it is off screen, so it costs nothing when nobody can see it. A pointer over an inner ring is over the outer one too, so both pause.

```html
<moul-orbit pause-on-hover>…</moul-orbit>
```

## Accessibility

`<moul-orbit>` is never focusable and adds no role. Its items keep their own semantics and screen readers read them in DOM order, the outer ring's items first, then the centre. Give each image an `alt`, and an icon a name with `role="img"` and `aria-label`, as in the examples above. The path is drawn for the eye only and is `aria-hidden`.

Links and buttons on the ring take focus as usual, and any focus inside holds the orbit still, so a keyboard user never chases a moving target. Each item stays upright as it travels, so its text and icons never turn on their side.

Where the system forces its own colours, as in Windows high contrast mode, the path is not drawn.

Under `prefers-reduced-motion: reduce` nothing turns: the items rest at their places on the ring, upright, as a still picture.

## Attributes and properties

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `radius` | `radius` | `number` (px) | `120` |
| `duration` | `duration` | `number` (seconds per turn) | `20` |
| `is-reverse` | `isReverse` | `boolean` | `false` |
| `show-path` | `showPath` | `boolean` | `false` |
| `pause-on-hover` | `pauseOnHover` | `boolean` | `false` |

| Slot | Description |
| :-- | :-- |
| (default) | The items, each one an element. |
| `center` | Content for the middle, such as a logo or another `moul-orbit`. |

| Part | Description |
| :-- | :-- |
| `orbit` | The square that holds the ring and the centre. |
| `path` | The circle drawn along the ring, with `show-path`. |
| `ring` | The turning layer that carries the items. |
| `center` | The box that centres the `center` slot. |

| CSS property | Description | Default |
| :-- | :-- | :-- |
| `--orbit-item-size` | The width and height of each item, and the room left round the ring for them. | `2.5rem` |
| `--orbit-path-color` | The colour of the path. | `var(--color-border)` |
