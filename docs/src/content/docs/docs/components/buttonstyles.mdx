## Styling a button

`::part(button)` reaches the native `<button>` inside `moul-button`, so a rule on it can set the background, border, radius, shadow and type, and `:hover`, `:active` and `:focus-visible` work after it. `::part(hover)`, `::part(content)` and the other parts reach the pieces inside. The `effect` and `is-pulsing` attributes add motion, and four CSS properties on the element tune it: `--button-effect-color`, `--button-effect-duration`, `--button-pulse-color` and `--button-pulse-duration` (see [Button](/docs/components/button/#effects)). Every colour below is a theme token, so each look follows the light and dark themes.

```css
moul-button.cta::part(button) {
  border-radius: var(--radius-md);
  font-weight: var(--font-weight-semibold);
}

moul-button.cta {
  --button-effect-color: var(--color-chart-5);
}
```

Three things to know before you write your own:

- A rule from your page wins over the button's own rules, whatever its specificity. Set `background` and the variant's hover colour stops showing, so set `:hover` too.
- The focus ring is a `box-shadow`. A look that sets `box-shadow` replaces it, so add `var(--focus-ring)` back on `:focus-visible`, as the 3D press look does.
- The button already fades its background, text and border colours, shadow, transform and opacity, and stops fading under reduced motion. Change only those on hover and press and the fades come for free. Anything else you transition needs its own reduced-motion rule, as the arrow look shows.
