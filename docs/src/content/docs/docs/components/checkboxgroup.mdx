# CheckboxGroup

The `<moul-checkbox-group>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

## Preview

<ComponentPreview>
  <moul-checkbox-group label="Email Preferences">
  <moul-checkbox checked>Security alerts</moul-checkbox>
  <moul-checkbox checked>Product updates</moul-checkbox>
  <moul-checkbox>Newsletter</moul-checkbox>
</moul-checkbox-group>
</ComponentPreview>

## Import

```ts
import '@moul-dev/ui';
```

## HTML Usage

```html
<moul-checkbox-group label="Options">
  <moul-checkbox>Option A</moul-checkbox>
  <moul-checkbox>Option B</moul-checkbox>
</moul-checkbox-group>
```
