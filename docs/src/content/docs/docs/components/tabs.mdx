import ComponentPreview from '@/components/ComponentPreview.astro';

`<moul-tabs>` pairs `<moul-tab>` and `<moul-tab-panel>` by `key`. The indicator glides to the selected tab and arrow keys move between tabs.

## Line

<ComponentPreview align="stretch">

  <moul-tab key="analytics">Analytics</moul-tab>

  <moul-tab key="billing" is-disabled>Billing</moul-tab>

</moul-tabs>
</ComponentPreview>

## API reference

### `<moul-tabs>`

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `selected-key` | `selectedKey` | `string` | `''` |
| `orientation` | `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` |
| `variant` | `variant` | `'line' \| 'pill' \| 'enclosed'` | `'pill'` |

| Event | Type |
| :-- | :-- |
| `selectionchange` | `CustomEvent` |

| Slot | Description |
| :-- | :-- |
| `tab` | — |
| `(default)` | — |

**CSS parts:** `indicator`, `base`, `tablist`, `panels`

### `<moul-tab>`

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `key` | `key` | `string` | `''` |
| `is-disabled` | `isDisabled` | `boolean` | `false` |
| `is-selected` | `isSelected` | `boolean` | `false` |

| Slot | Description |
| :-- | :-- |
| `(default)` | — |

**CSS parts:** `base`

### `<moul-tab-panel>`

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `key` | `key` | `string` | `''` |

| Slot | Description |
| :-- | :-- |
| `(default)` | — |
