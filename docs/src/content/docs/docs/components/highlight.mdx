`<moul-highlight>` draws a mark on the phrase that matters, the way you would with a highlighter pen: a band behind the words, a thick stroke under them, or a quick box or ring around them. It draws once, the first time the words scroll into view, and the text keeps its own colour.

It lives in the effects entry, with the rest of the landing kit:

```js

```


## Effects

`effect` sets the kind of mark. `marker` (the default) sweeps a translucent band behind the words. `underline` draws a thick stroke under them. Both are drawn from the start of the words to the end, and when the words wrap they are drawn line after line. `box` draws a hand-drawn rectangle around the words and `circle` a hand-drawn ring; both keep the words on one line.

## Tone and colour

`tone` colours the mark: `warning` (the default, a yellow marker), `primary`, `accent`, `success` or `error`. The marker band mixes the colour at 40% with transparent so the text shows through; underline, box and circle use it solid. `--highlight-color` replaces the tone's colour with your own, and the marker still mixes it at 40%.

## Timing

`delay` waits after the words enter the viewport (0 by default) and `duration` is how long the drawing takes (700 by default), both in milliseconds. A delay lets a heading arrive before its key phrase is marked.

```html
<moul-reveal>
  <h2>Ship your <moul-highlight delay="600">landing page</moul-highlight> this week</h2>
</moul-reveal>
```

## Drawing again

`is-drawn` is set when the mark is drawn. `play()` erases the mark and draws it again, which is what the replay buttons on this page call.

```js
document.querySelector('moul-highlight').play()
```

## Accessibility

`<moul-highlight>` is never focusable and adds no role. The words are read as they are, and the drawn mark is decoration that screen readers do not see. When the emphasis carries meaning, say so in the markup too: put the words in `<mark>` or `<strong>` inside the element. A `<mark>` placed directly inside loses the browser's yellow background, so only the drawn mark shows.

```html
<moul-highlight><mark>cancel any time</mark></moul-highlight>
```

The marker band is a 40% mix of the tone colour, so the text over it keeps most of its contrast. Where the system forces its own colours, as in Windows high contrast mode, the mark uses the system text colour.

Under `prefers-reduced-motion: reduce` the mark is drawn from the start, with no animation. It is also drawn when printing.

## Attributes and properties

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `effect` | `effect` | `'marker' \| 'underline' \| 'box' \| 'circle'` | `'marker'` |
| `tone` | `tone` | `'primary' \| 'accent' \| 'success' \| 'warning' \| 'error'` | `'warning'` |
| `delay` | `delay` | `number` (ms) | `0` |
| `duration` | `duration` | `number` (ms) | `700` |
| `is-drawn` | `isDrawn` | `boolean`, set by the element | `false` |

| Method | Description |
| :-- | :-- |
| `play()` | Erases the mark and draws it again. |

| Slot | Description |
| :-- | :-- |
| (default) | The words to mark. |

| CSS property | Description | Default |
| :-- | :-- | :-- |
| `--highlight-color` | The colour of the mark, in place of the tone's. | The tone's colour |
