# Spinner

The `<moul-spinner>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

## Import

```ts
import '@moul-dev/ui';
```

## HTML Usage

```html
<moul-spinner size="md"></moul-spinner>
```

## Attributes & Properties

| Name | Type | Default |
| :--- | :--- | :--- |
| `size` | `SpinnerSize` | `'md'` |
| `label` | `string` | `'Loading'` |
