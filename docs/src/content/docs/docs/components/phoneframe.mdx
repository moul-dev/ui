`<moul-phone-frame>` draws a phone around a screenshot or a video, for an app's landing page or a mobile feature. It is CSS only, with no images: a dark bezel, a cut-out at the top of the screen and side buttons. The shapes are generic, with no logos or brand marks, and the whole phone scales with one width.

```

```

## Variants

`variant="iphone"` (the default) is a rounded slab with a pill-shaped cut-out at the top of the screen, three buttons on the left and one on the right. `variant="android"` has slightly squarer corners, a round camera hole in the middle of the top and two buttons on the right. An unknown value falls back to `iphone`.

The screen has the aspect ratio of a modern phone: 393:852 for `iphone` and 412:915 for `android`. A full-screen screenshot of that shape, such as 1179 × 2556 or 1080 × 2400 pixels, fits without cropping.

## Size

`--phone-frame-width` sets the width of the phone, side buttons included; it is `18rem` by default and never wider than its container. The bezel, the corners, the cut-out and the buttons are all fractions of that width, so the phone keeps its proportions at any size.

## Bezel colour

The bezel is dark in both themes, as a phone is, from `--color-eclipse`. `--phone-frame-bezel` sets another colour; the band around the edge and the buttons are a lighter shade of it.

## Screen content

An image or a video covers the whole screen, cropped to fill it if its shape differs. Any other markup starts at the top of the screen and is clipped to its rounded corners; give it `position: absolute; inset: 0` to fill the screen. The phone is a size container, so `cqi` units in that markup are fractions of the phone's width and scale with it, as the screens on this page do. Leave room at the top for the cut-out.

```html
<moul-phone-frame>
  <video src="/onboarding.mp4" controls muted playsinline aria-label="Signing up in three steps"></video>
</moul-phone-frame>

<moul-phone-frame>
  <div class="app-screen" style="position: absolute; inset: 0; padding: 16cqi 5cqi 6cqi">…</div>
</moul-phone-frame>
```

## Accessibility

`<moul-phone-frame>` is never focusable and adds no role. The bezel, the cut-out and the buttons are decoration hidden from screen readers, so they read only what is on the screen, with its own semantics. Give a screenshot alt text that says what the reader would learn from it; if the text beside it already says everything, use `alt=""`.

The frame never moves, so `prefers-reduced-motion` changes nothing. A video on the screen is your own content: if it plays on its own, pause it under reduced motion as you would anywhere else.

## API reference

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `variant` | `variant` | `'iphone' \| 'android'` | `'iphone'` |

| Slot | Description |
| :-- | :-- |
| `(default)` | The screen. An image or a video covers it; any other markup starts at the top. |

| Part | Description |
| :-- | :-- |
| `base` | The phone's body: the bezel around the screen. |
| `screen` | The screen, which clips its content to the rounded corners. |
| `island` | The pill-shaped cut-out at the top of the screen (`iphone`). |
| `camera` | The round camera hole at the top of the screen (`android`). |

| CSS property | Description |
| :-- | :-- |
| `--phone-frame-width` | The phone's width, side buttons included. Defaults to `18rem`. |
| `--phone-frame-bezel` | The colour of the bezel. Defaults to `var(--color-eclipse)`. |
