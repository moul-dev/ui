# Avatar

The `<moul-avatar>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

## Preview

<ComponentPreview>
  <moul-avatar-group>
  <moul-avatar initials="PT"></moul-avatar>
  <moul-avatar initials="JD"></moul-avatar>
  <moul-avatar initials="AL"></moul-avatar>
</moul-avatar-group>
</ComponentPreview>

## Import

```ts
import '@moul-dev/ui';
```

## HTML Usage

```html
<moul-avatar initials="PT" status="online"></moul-avatar>
<moul-avatar-group max="3">
  <moul-avatar initials="PT"></moul-avatar>
  <moul-avatar initials="JD"></moul-avatar>
</moul-avatar-group>
```
