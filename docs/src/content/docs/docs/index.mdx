Moul UI is a library of accessible Web Components for teams that want one consistent, modern UI baseline across every web stack.

Each component is a standard custom element built on **Lit 3** and **Shadow DOM**, styled by a runtime-tunable **CSS design token layer (`light-dark()` + `oklch()`)**. Register the elements once, then use them anywhere HTML runs.

---

## Why Web Components?

<CardGrid>
  <Card title="Framework Agnostic" icon="puzzle">
    Use the same custom elements in Astro, Next.js, Remix, Svelte, Vue, or static HTML, with no wrappers or adapter layers.
  </Card>
  <Card title="Encapsulated, Themeable Styles" icon="pencil">
    Shadow DOM keeps each component's styles and internals isolated from your app, while CSS tokens let you retheme everything from the outside.
  </Card>
  <Card title="Standards-First APIs" icon="laptop">
    Built directly on native browser primitives including `<dialog>`, Popover API, CSS Anchor Positioning, and `ElementInternals`.
  </Card>
  <Card title="Native Form Support" icon="approve-check">
    Form controls are form-associated through `ElementInternals`, so they submit their values and report validity inside a regular `<form>`.
  </Card>
</CardGrid>

## Installation

<Steps>
1. ### Install the Package
   
   Add the library to your workspace:

   <Tabs>
     <TabItem label="bun">
       ```bash
       bun add @moul-dev/ui
       ```
     </TabItem>
     <TabItem label="npm">
       ```bash
       npm install @moul-dev/ui
       ```
     </TabItem>
     <TabItem label="pnpm">
       ```bash
       pnpm add @moul-dev/ui
       ```
     </TabItem>
     <TabItem label="yarn">
       ```bash
       yarn add @moul-dev/ui
       ```
     </TabItem>
   </Tabs>

2. ### Import Stylesheet & Elements

   Import `@moul-dev/ui/style.css` in your global stylesheet and import `@moul-dev/ui` in your application client script:

   ```ts
   // Import global token definitions
   import '@moul-dev/ui/style.css';

   // Register all custom elements
   import '@moul-dev/ui';
   ```

3. ### Use Custom Elements Directly in HTML

   ```html
   <moul-button variant="primary">Get Started</moul-button>
   <moul-badge variant="success">Active</moul-badge>
   ```

     <moul-badge variant="success">Active</moul-badge>
   </ComponentPreview>
</Steps>
