# Sidebar

The `<moul-sidebar>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

    <moul-sidebar-item value="metrics">Metrics</moul-sidebar-item>
  </moul-sidebar-group>
</moul-sidebar>
</ComponentPreview>

## Import

```ts
import '@moul-dev/ui';
```

## HTML Usage

```html
<moul-sidebar>
  <moul-sidebar-group label="Navigation">
    <moul-sidebar-item value="home">Home</moul-sidebar-item>
  </moul-sidebar-group>
</moul-sidebar>
```

## Attributes & Properties

| Name | Type | Default |
| :--- | :--- | :--- |
| `layout` | `SidebarLayout` | `'sidebar-framed'` |
| `dense` | `boolean` | `false` |
| `collapsed` | `boolean` | `false` |
| `selected-key` | `string` | `''` |

## Events

| Event Name | Description |
| :--- | :--- |
| `selectionchange` | Dispatched when element fires selectionchange |
| `collapsechange` | Dispatched when element fires collapsechange |
