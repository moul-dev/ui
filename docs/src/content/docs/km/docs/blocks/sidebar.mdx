`<moul-sidebar>` lays out navigation beside your main content. The selection pill glides between items and the aside collapses to an icon rail.

| `dense` | `dense` | `boolean` | `false` |
| `collapsed` | `collapsed` | `boolean` | `false` |
| `selected-key` | `selectedKey` | `string` | `''` |

| Event | Type |
| :-- | :-- |
| `selectionchange` | `CustomEvent` |
| `collapsechange` | `CustomEvent` |

| Slot | Description |
