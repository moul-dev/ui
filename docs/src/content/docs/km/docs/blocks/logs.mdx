# Logs (សមាសភាគ)

The `<moul-logs>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

## Preview

<ComponentPreview>
  <moul-logs style="height: 220px; width: 100%;"></moul-logs>
</ComponentPreview>

## Import

```ts
import '@moul-dev/ui';
```

## HTML Usage

```html
<moul-logs></moul-logs>
```
