# Modal (សមាសភាគ)

The `<moul-modal>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

## Preview

<ComponentPreview>
  <moul-button variant="primary">Launch Modal</moul-button>
</ComponentPreview>

## Import

```ts
import '@moul-dev/ui';
```

## HTML Usage

```html
<moul-modal title="Dialog Title">
  <p>Modal dialog body content.</p>
</moul-modal>
```

## Attributes & Properties

| Name | Type | Default |
| :--- | :--- | :--- |
| `is-open` | `boolean` | `false` |
| `size` | `ModalSize` | `'md'` |
| `is-dismissable` | `boolean` | `true` |

## Events

| Event Name | Description |
| :--- | :--- |
| `openchange` | Dispatched when element fires openchange |
