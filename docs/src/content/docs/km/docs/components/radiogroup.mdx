`<moul-radio-group>` holds one value. Arrow keys move both focus and selection, and the dot springs into the newly chosen radio.

<ComponentPreview>
<moul-radio-group label="Plan" value="pro">
  <moul-radio value="free">Free</moul-radio>
  <moul-radio value="pro">Pro — $29/mo</moul-radio>
  <moul-radio value="enterprise">Enterprise</moul-radio>
  <moul-radio value="legacy" is-disabled>Legacy (unavailable)</moul-radio>
</moul-radio-group>
</ComponentPreview>

## API reference

### `<moul-radio-group>`

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `name` | `name` | `string` | `''` |
| `value` | `value` | `string` | `''` |
| `label` | `label` | `string` | `''` |
| `is-disabled` | `isDisabled` | `boolean` | `false` |
| `is-required` | `isRequired` | `boolean` | `false` |
| `orientation` | `orientation` | `'horizontal' \| 'vertical'` | `'vertical'` |

| Event | Type |
| :-- | :-- |
| `change` | `CustomEvent` |

| Slot | Description |
| :-- | :-- |
| `label` | — |
| `(default)` | — |

**CSS parts:** `base`, `label`, `group`
