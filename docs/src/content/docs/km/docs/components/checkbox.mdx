# Checkbox (សមាសភាគ)

The `<moul-checkbox>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

## Preview

<ComponentPreview>
  <moul-checkbox checked>Receive release notifications</moul-checkbox>
</ComponentPreview>

## Import

```ts
import '@moul-dev/ui';
```

## HTML Usage

```html
<moul-checkbox checked>I agree to terms</moul-checkbox>
```
