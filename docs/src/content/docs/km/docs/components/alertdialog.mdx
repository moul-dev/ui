# AlertDialog (សមាសភាគ)

The `<moul-alert-dialog>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

## Preview

<ComponentPreview>
  <moul-button variant="danger">Delete Workspace</moul-button>
</ComponentPreview>

## Import

```ts
import '@moul-dev/ui';
```

## HTML Usage

```html
<moul-alert-dialog title="Delete Project?" description="This action cannot be undone.">
  <moul-button slot="actions" variant="danger">Confirm Delete</moul-button>
</moul-alert-dialog>
```

## Attributes & Properties

| Name | Type | Default |
| :--- | :--- | :--- |
| `is-open` | `boolean` | `false` |
| `tone` | `SemanticTone` | `'error'` |
| `size` | `AlertDialogSize` | `'md'` |

## Events

| Event Name | Description |
| :--- | :--- |
| `openchange` | Dispatched when element fires openchange |
| `confirm` | Dispatched when element fires confirm |
| `cancel` | Dispatched when element fires cancel |
