# PercentageBar (សមាសភាគ)

The `<moul-percentage-bar>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

## Preview

<ComponentPreview>
  <moul-percentage-bar value="75" style="width: 100%;"></moul-percentage-bar>
</ComponentPreview>

## Import

```ts
import '@moul-dev/ui';
```

## HTML Usage

```html
<moul-percentage-bar value="60"></moul-percentage-bar>
```

## Attributes & Properties

| Name | Type | Default |
| :--- | :--- | :--- |
| `value` | `number` | `0` |
| `size` | `PercentageBarSize` | `'md'` |
| `tone` | `SemanticTone` | `'primary'` |
| `show-label` | `boolean` | `true` |
| `label` | `string` | `''` |
| `show-value-text` | `boolean` | `true` |
| `color` | `string` | `''` |
