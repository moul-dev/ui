`<moul-doughnut-chart>` shows shares of a total with an optional center label.

<ComponentPreview>
<moul-doughnut-chart height="260" center-label="990" center-sublabel="Visitors" style="width: min(100%, 22rem)" data-props='{"data":[{"name":"Organic","value":420},{"name":"Referral","value":260},{"name":"Social","value":190},{"name":"Email","value":120}]}'></moul-doughnut-chart>
</ComponentPreview>

```html
<moul-doughnut-chart height="260" center-label="990" center-sublabel="Visitors" style="width: min(100%, 22rem)"></moul-doughnut-chart>
```

```js
const doughnutChart = document.querySelector('moul-doughnut-chart')
doughnutChart.data = [
  {
    "name": "Organic",
    "value": 420
  },
  {
    "name": "Referral",
    "value": 260
  },
  {
    "name": "Social",
    "value": 190
  },
  {
    "name": "Email",
    "value": 120
  }
]
```
