## Layers and depth

Every child is a layer. Position the layers however you like, usually absolutely inside the element, which is `position: relative`. Give each one a `data-depth`, usually between -1 and 1: 0 stays still, 1 moves the full `strength`, and a negative depth moves the other way, which reads as nearer than the pointer. A child without a `data-depth` stays still. Changing `data-depth` later takes effect at once.

`strength` is how far, in pixels, a layer of depth 1 travels with the pointer at the element's edge; it is 24 by default. Layers move past their edges by up to that much, so let them overhang the element a little and give the element `overflow: clip`.

Each layer moves by the CSS `translate` property, which leaves `transform` free for your own use. Position layers with `inset`, margins or `transform`; a `translate` of your own on a layer would replace the parallax.

## Following the pointer across the page

By default the layers follow the pointer while it is over the element and drift back to the centre when it leaves. `scope="page"` follows the pointer anywhere on the page, measured from the element's centre, so a hero background reacts before the pointer reaches it. The layers stop at their furthest when the pointer is past the element's edge, and the element does no work while it is off screen.

## Pointers and cost

Only a mouse or a pen moves the layers; on a touch screen they stay still. However many layers it holds, the element writes two numbers once per frame, and each layer works out its own offset in CSS from its depth, which is written once. The layers move by transforms alone, so the page is never laid out again. A short transition, `--pointer-parallax-duration` long, smooths the movement into a float.

## Accessibility

The element is never focusable and adds no role, and the layers keep their own semantics and are read in order. Shapes and pictures that only decorate should be hidden from screen readers by you, with `aria-hidden="true"` or an empty `alt`.

Under `prefers-reduced-motion: reduce` every layer stays in its place. The element reacts to the setting as soon as it changes.

## Attributes and properties

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `strength` | `strength` | `number` (px) | `24` |
| `scope` | `scope` | `'element' \| 'page'` | `'element'` |
| | `offset` | `{ x: number, y: number }`, read only, each -1 to 1 | `{ x: 0, y: 0 }` |

On each child:

| Attribute | Type | Default |
| :-- | :-- | :-- |
| `data-depth` | `number`, usually -1 to 1 | none: the child stays still |

| Slot | Description |
| :-- | :-- |
| (default) | The layers, each an element with a `data-depth`. |

| CSS property | Description | Default |
| :-- | :-- | :-- |
| `--pointer-parallax-duration` | How long a layer takes to catch up with the pointer, and to drift back. | `600ms` |
