`<moul-ripple>` draws concentric rings round its centre and pulses them outward, one after another, behind whatever sits in the middle. Use it to draw the eye to one thing: a call to action, a "live" status, the logo of an integration. The rings grow fainter outward and fade out, so the effect has no hard edge.

<ComponentPreview align="stretch" minHeight="320px">
  <moul-ripple style="min-height: 22rem; gap: 0.75rem; text-align: center">
    <moul-avatar name="Sophea Chan" size="lg"></moul-avatar>
    <moul-typography variant="body">Sophea is presenting</moul-typography>
  </moul-ripple>
  <LandingKitDemo />
</ComponentPreview>

It lives in the effects entry, with the rest of the landing kit:

```js
import '@moul-dev/web-component/effects'
```

```html
<moul-ripple style="min-height: 22rem">
  <moul-avatar name="Sophea Chan" size="lg"></moul-avatar>
  <p>Sophea is presenting</p>
</moul-ripple>
```

## Layout

The rings are centred on the element, and the element centres its content: it is a grid that stacks its children in the middle, one under another. It is at least as tall as the innermost ring and two more, and adds no padding or background colour of its own. Give it a height to show more rings; the outer ones fade into the element's edges.

To lay the content out another way, set your own `display` on the element, such as `display: block` or `display: flex`. The rings stay centred on the element whatever its layout.

```css
moul-ripple.banner {
  display: flex;
  align-items: center;
  justify-content: space-between;
}
```

## Rings

`count` is the number of rings, from 1 to 12 (6 by default). Each ring is wider than the one inside it by the same step, and fainter.

<ComponentPreview align="stretch" minHeight="320px">
  <div style="display: grid; grid-template-columns: repeat(auto-fit, minmax(14rem, 1fr)); gap: 1rem">
    <moul-ripple count="3" style="min-height: 16rem; --ripple-size: 6rem; --ripple-gap: 3rem"><span class="demo-label">3 rings</span></moul-ripple>
    <moul-ripple count="10" style="min-height: 16rem; --ripple-size: 4rem; --ripple-gap: 1.5rem"><span class="demo-label">10 rings</span></moul-ripple>
  </div>
</ComponentPreview>

```html
<moul-ripple count="10" style="--ripple-size: 4rem; --ripple-gap: 1.5rem">…</moul-ripple>
```

## Colours, size and speed

The rings are tinted and outlined in `--color-fg` at low strength, so they darken a light page and lighten a dark one. Four CSS properties change the look:

- `--ripple-size` is the diameter of the innermost ring (`10rem`). Make it a little wider than the content in the middle.
- `--ripple-gap` is how much wider each ring is than the one inside it (`4.5rem`).
- `--ripple-color` is the colour the rings are tinted and outlined with (`var(--color-fg)`). It is used at low strength, so set a full-strength colour.
- `--ripple-duration` is the length of one pulse (`2s`).

<ComponentPreview align="stretch" minHeight="320px">
  <moul-ripple style="--ripple-color: var(--color-accent); --ripple-size: 8rem; --ripple-gap: 3.5rem; --ripple-duration: 3s; min-height: 22rem">
    <moul-button>Start a call</moul-button>
  </moul-ripple>
</ComponentPreview>

```css
moul-ripple.call {
  --ripple-color: var(--color-accent);
  --ripple-size: 8rem;
  --ripple-gap: 3.5rem;
  --ripple-duration: 3s;
}
```

The animation is CSS only, and pauses while the rings are off screen.

## Use as a layer

To put the rings behind a section you already have, leave the element empty and position it over the section, behind the content. The rings centre on the section; reset the element's own minimum height so it never grows past the section.

```html
<section style="position: relative; isolation: isolate">
  <moul-ripple style="position: absolute; inset: 0; z-index: -1; min-height: 0"></moul-ripple>
  <h2>Join the beta</h2>
</section>
```

`isolation: isolate` on the section keeps the `z-index: -1` inside it, so the rings paint above the section's own background and below its content.

## Accessibility

The rings are decoration. Their layer is hidden from screen readers with `aria-hidden`, and the element adds no role and never takes focus. The content in the middle is read, selected and focused as usual; the rings paint behind it and take no pointer events.

The rings are faint, at most 15% of the text colour for an outline and 3.5% for a fill, so text in front keeps nearly all its contrast. The pulse is slow and small: the rings shrink to 90% and back over two seconds.

Where the system forces its own colours, as in Windows high contrast mode, the rings are not drawn.

Under `prefers-reduced-motion: reduce` the rings stay still at their resting size.

## Attributes and properties

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `count` | `count` | `number`, 1 to 12 | `6` |

| Slot | Description |
| :-- | :-- |
| (default) | The content in the middle of the rings, centred in the element. |

| Part | Description |
| :-- | :-- |
| `background` | The decorative layer behind the content that holds the rings and carries the fade. |

| CSS property | Description | Default |
| :-- | :-- | :-- |
| `--ripple-size` | The diameter of the innermost ring. | `10rem` |
| `--ripple-gap` | How much wider each ring is than the one inside it. | `4.5rem` |
| `--ripple-color` | The colour the rings are tinted and outlined with, at low strength. | `var(--color-fg)` |
| `--ripple-duration` | The length of one pulse. | `2s` |
