## Sheet

`is-sheet` turns the drawer into a bottom sheet, whatever `placement` says. It gets a grab handle on top and rounded top corners, grows with its content up to 90% of the viewport (`size` does not apply), and pads its bottom edge clear of the home indicator. Drag it down to dismiss: it closes when let go past a third of its height or flicked down, and springs back otherwise. The backdrop clears as it goes.

- The handle, header and footer always drag. The scrolling body drags the sheet only from the top of its content and only downward, so the content still scrolls. A press on a text field never drags, so its text can still be selected.
- Dragging up stretches and springs back. With `is-dismissable` set to false, dragging down does the same and the sheet stays open.
- A drag that closes the sheet fires the same `openchange` (`detail.isOpen` is `false`) as `Escape` or a click outside.
- The handle is decorative: screen readers skip it and `Tab` never lands on it, so focus still moves to the first control on open. Dragging is a pointer gesture; `Escape` closes the sheet from the keyboard. Give a sheet for touch screen readers its own close or done button.
- Under reduced motion the sheet still follows the finger, but on release it closes or returns at once instead of springing.
- The bottom padding includes `env(safe-area-inset-bottom)`, which is only non-zero when the page's viewport meta has `viewport-fit=cover`.

## API reference

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `is-open` | `isOpen` | `boolean` | `false` |
| `placement` | `placement` | `'left' \| 'right' \| 'top' \| 'bottom'` | `'right'` |
| `size` | `size` | `'sm' \| 'md' \| 'lg'` | `'md'` |
| `is-dismissable` | `isDismissable` | `boolean` | `true` |
| `is-sheet` | `isSheet` | `boolean` | `false` |

| Event | Type |
| :-- | :-- |
| `openchange` | `CustomEvent` |

| Slot | Description |
| :-- | :-- |
| `header` | Title row at the top of the panel |
| `(default)` | The body, which scrolls when it overflows |
| `footer` | Actions at the bottom of the panel |

**CSS parts:** `base`, `dialog`, `handle` (sheets only), `header`, `body`, `footer`

With `is-sheet`, `placement` and `size` are ignored: the sheet is attached to the bottom edge and fits its content. `is-dismissable` set to false stops a click outside and a downward drag from closing the drawer; `Escape` always closes it.
