# Slider (សមាសភាគ)

The `<moul-slider>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

## Preview

<ComponentPreview>
  <moul-slider value="65" min="0" max="100" style="width: 280px;"></moul-slider>
</ComponentPreview>

## Import

```ts
import '@moul-dev/ui';
```

## HTML Usage

```html
<moul-slider value="50" min="0" max="100"></moul-slider>
```
