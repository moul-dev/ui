# NumberField (សមាសភាគ)

The `<moul-number-field>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

## Preview

<ComponentPreview>
  <moul-number-field label="Replicas" value="3" min="1" max="10"></moul-number-field>
</ComponentPreview>

## Import

```ts
import '@moul-dev/ui';
```

## HTML Usage

```html
<moul-number-field label="Count" value="1"></moul-number-field>
```
