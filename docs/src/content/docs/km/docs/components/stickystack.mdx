`<moul-sticky-stack>` piles its children up as the reader scrolls. Each child sticks near the top of the screen, the next one slides up over it a little lower, and the edges of the earlier ones peek out above it like a stack of cards. A card that is covered shrinks slightly and dims, so the pile reads as depth.

It lives in the effects entry:

```js
import '@moul-dev/web-component/effects'
```

```html
<moul-sticky-stack>
  <article class="card">…</article>
  <article class="card">…</article>
  <article class="card">…</article>
</moul-sticky-stack>
```

Every child is a card, in any markup you like. Give them an opaque background, since each one slides over the last. They stay where you put them in the DOM, so your own styles and links keep working.

## How it sticks

The stack is plain CSS `position: sticky`. The first child sticks `--sticky-stack-top` from the top of the scrolling box, and each next one `--sticky-stack-step` lower, which is how much of each earlier card stays in view. Before they stack, the children are `--sticky-stack-gap` apart.

```css
moul-sticky-stack {
  --sticky-stack-top: 5rem; /* below a sticky navbar */
  --sticky-stack-step: 1.25rem;
  --sticky-stack-gap: 3rem;
}
```

The pile holds together until the end of the stack scrolls up past it, then leaves as one. To keep the finished pile on screen a little longer, pad the end of the `stack` part, or the element itself:

```css
moul-sticky-stack::part(stack) {
  padding-block-end: 30vh;
}
```

Sticky elements only stick inside the box that scrolls, so no element between the stack and that box may set `overflow: hidden`. Inside a scrolling panel, as in the demo above, the stack follows the panel; nothing else is needed.

## Shrink and dim

Each covered card shrinks from its top edge while the cards after it arrive, and the one at the bottom of the pile ends at `min-scale`, 0.9 by default. The cards in between end evenly between that and full size. `min-scale="1"` turns the shrink off. `--sticky-stack-dim` is how much the bottom card darkens, 0.2 by default; `0` turns it off.

```html
<moul-sticky-stack min-scale="0.85" style="--sticky-stack-dim: 0.35">…</moul-sticky-stack>
```

The stack changes only the `scale` and `filter` of each card, never a transform of your own, and never its size, so the page is not laid out again while the reader scrolls. Where the browser has scroll-driven animations a native view timeline drives every card, and no script runs while the reader scrolls; elsewhere one passive scroll listener writes a single number per frame. The stack measures its cards only when they or the screen change size.

## Whole sections

The children can be full-height sections instead of cards, for a page that turns over one section at a time. Set the step and the gap to nothing so each section covers the last completely.

```html
<moul-sticky-stack min-scale="0.94" style="--sticky-stack-top: 0; --sticky-stack-step: 0; --sticky-stack-gap: 0">
  <section style="min-height: 100vh">…</section>
  <section style="min-height: 100vh">…</section>
  <section style="min-height: 100vh">…</section>
</moul-sticky-stack>
```

## Accessibility

The stack adds no role and never takes focus: the cards are read, and their links and buttons reached with Tab, in their order. A card that later cards cover would hide a control focused inside it, so when keyboard focus moves into a covered card (Shift+Tab back up the pile, for example) the stack scrolls back until that card is on top. Focus that comes from a pointer, on the strip of a card that peeks out, leaves the scroll alone.

Under `prefers-reduced-motion: reduce` the cards still stick and stack, because that is layout the reader moves with their own scrolling, but they no longer shrink or dim, and the scroll back to a focused card jumps instead of gliding. When printing, the cards lie flat one after another.

## Attributes and properties

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `min-scale` | `minScale` | `number`, 0.5 to 1 | `0.9` |

| Slot | Description |
| :-- | :-- |
| (default) | The cards or sections to stack, each one an element. |

| Part | Description |
| :-- | :-- |
| `stack` | The column that holds the children. Pad its end to hold the finished pile in view a little longer. |

| CSS property | Description | Default |
| :-- | :-- | :-- |
| `--sticky-stack-top` | Where the first child sticks, from the top of the scrolling box. | `var(--spacing-4)` |
| `--sticky-stack-step` | How much lower each next child sticks, so the earlier ones peek out. | `var(--spacing-4)` |
| `--sticky-stack-gap` | The space between children before they stack. | `var(--spacing-8)` |
| `--sticky-stack-dim` | How much the bottom card darkens, from 0 to 1. | `0.2` |
