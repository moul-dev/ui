There is no separate autocomplete element: `<moul-combobox>` already filters its items against the typed text. Give it suggestions and listen for `inputchange` to fetch more.

## API reference

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `name` | `name` | `string` | `''` |
| `selected-key` | `selectedKey` | `string` | `''` |
| `input-value` | `inputValue` | `string` | `''` |
| `placeholder` | `placeholder` | `string` | `''` |
| `label` | `label` | `string` | `''` |
| `is-disabled` | `isDisabled` | `boolean` | `false` |
| `is-required` | `isRequired` | `boolean` | `false` |
| `is-open` | `isOpen` | `boolean` | `false` |

| Event | Type |
| :-- | :-- |
| `selectionchange` | `CustomEvent` |
| `inputchange` | `CustomEvent` |
| `change` | `CustomEvent` |
| `input` | `CustomEvent` |

| Slot | Description |
| :-- | :-- |
| `label` | — |
| `(default)` | — |
| `empty` | — |

**CSS parts:** `popover`, `base`, `label`, `input-container`, `input`, `toggle-btn`, `empty`
