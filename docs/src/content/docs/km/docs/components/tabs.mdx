# Tabs (សមាសភាគ)

The `<moul-tabs>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

## Import

```ts
import '@moul-dev/ui';
```

## HTML Usage

```html
<moul-tabs>
  <moul-tab-list>
    <moul-tab value="a" selected>Tab A</moul-tab>
    <moul-tab value="b">Tab B</moul-tab>
  </moul-tab-list>
  <moul-tab-panel value="a">Content A</moul-tab-panel>
  <moul-tab-panel value="b">Content B</moul-tab-panel>
</moul-tabs>
```

## Attributes & Properties

| Name | Type | Default |
| :--- | :--- | :--- |
| `selected-key` | `string` | `''` |
| `orientation` | `TabsOrientation` | `'horizontal'` |
| `variant` | `TabsVariant` | `'line'` |
