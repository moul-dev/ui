# TextArea (សមាសភាគ)

The `<moul-text-area>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

## Import

```ts
import '@moul-dev/ui';
```

## HTML Usage

```html
<moul-text-area label="Notes" placeholder="Write here..."></moul-text-area>
```
