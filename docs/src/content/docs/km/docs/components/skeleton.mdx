## API reference

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `shape` | `shape` | `'line' \| 'circle' \| 'rect'` | `'line'` |
| `variant` | `variant` | `'pulse' \| 'wave'` | `'pulse'` |
| `width` | `width` | `string` | `''` |
| `height` | `height` | `string` | `''` |

**CSS parts:** `base`
