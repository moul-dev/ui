`<moul-checkbox-group>` groups checkboxes under one label and reports the checked values as an array.

<ComponentPreview>
<moul-checkbox-group label="Email preferences" description="Choose what lands in your inbox.">
  <moul-checkbox value="security" is-checked>Security alerts</moul-checkbox>
  <moul-checkbox value="product" is-checked>Product updates</moul-checkbox>
  <moul-checkbox value="newsletter">Newsletter</moul-checkbox>
</moul-checkbox-group>
</ComponentPreview>

```html
<moul-checkbox-group label="Email preferences" description="Choose what lands in your inbox.">
  <moul-checkbox value="security" is-checked>Security alerts</moul-checkbox>
  <moul-checkbox value="product" is-checked>Product updates</moul-checkbox>
  <moul-checkbox value="newsletter">Newsletter</moul-checkbox>
</moul-checkbox-group>
```

## API reference

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `name` | `name` | `string` | `''` |
| `value` | `value` | `string[]` | `[]` |
| `label` | `label` | `string` | `''` |
| `description` | `description` | `string` | `''` |
| `is-disabled` | `isDisabled` | `boolean` | `false` |
| `is-required` | `isRequired` | `boolean` | `false` |
| `orientation` | `orientation` | `'horizontal' \| 'vertical'` | `'vertical'` |

| Event | Type |
| :-- | :-- |
| `change` | `CustomEvent` |

| Slot | Description |
| :-- | :-- |
| `label` | — |
| `description` | — |
| `(default)` | — |

**CSS parts:** `base`, `label`, `description`, `group`
