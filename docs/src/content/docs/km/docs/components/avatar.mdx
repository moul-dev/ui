`<moul-avatar>` fades its image in once loaded and falls back to initials from `name`. `<moul-avatar-group>` overlaps avatars and summarises the overflow.

<ComponentPreview>
<div class="demo-row">
  <moul-avatar name="Sarah Chen" size="xs"></moul-avatar>
  <moul-avatar name="Marcus Brody" size="sm" status="online"></moul-avatar>
  <moul-avatar name="Elena Rostova" size="md" status="away"></moul-avatar>
  <moul-avatar name="Devon Vance" size="lg" status="busy"></moul-avatar>
  <moul-avatar name="Kim Ly" size="xl" shape="square"></moul-avatar>
</div>
</ComponentPreview>

## API reference

### `<moul-avatar>`

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `src` | `src` | `string` | `''` |
| `name` | `name` | `string` | `''` |
| `size` | `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | — |
| `shape` | `shape` | `'circle' \| 'square'` | `'circle'` |
| `status` | `status` | `'online' \| 'offline' \| 'away' \| 'busy' \| undefined` | — |
| `hasImageError` | `hasImageError` | `boolean` | `false` |

| Event | Type |
| :-- | :-- |
| `error` | `CustomEvent` |

| Slot | Description |
| :-- | :-- |
| `fallback` | — |

**CSS parts:** `image`, `initials`, `fallback`, `status`

### `<moul-avatar-group>`

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `max` | `max` | `number` | `5` |
| `size` | `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` |
| `totalAvatars` | `totalAvatars` | `number` | `0` |

| Slot | Description |
| :-- | :-- |
| `(default)` | — |

**CSS parts:** `overflow`
