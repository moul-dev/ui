`<moul-spinner>` is an accessible `role="status"` indicator; `label` is read to screen readers.

</div>

## API reference

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `size` | `size` | `'sm' \| 'md' \| 'lg'` | `'md'` |
| `label` | `label` | `string` | `'Loading'` |

**CSS parts:** `base`
