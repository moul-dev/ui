`<moul-spinner>` is an accessible `role="status"` indicator for a wait of unknown length; `label` is read to screen readers. It draws in the current text colour, so it takes the colour of whatever it sits in.

## Variants

`variant` picks the look. All four are calm on purpose: a loader is something people stare at.

| Variant | Look |
| :-- | :-- |
| `ring` (default) | A ring with one bright quarter that turns. |
| `dots` | Three dots that rise and fade in turn. |
| `shape` | A rounded square that turns a quarter and rounds into a circle, then back. |
| `orbit` | One dot that circles a faint track. |

An unknown `variant` falls back to `ring`.

## Accessibility

The spinner is a `role="status"` live region named by `label` ("Loading" unless you set it), and the label is also present as visually hidden text; the drawing is hidden from screen readers. It is not focusable. Say what is loading: "Loading invoices" tells someone more than "Loading".

Under reduced motion nothing turns or travels. The ring, the shape and the orbit's dot pulse their opacity slowly instead, and the dots pulse one after another, so the spinner still says "working".

## API reference

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `size` | `size` | `'sm' \| 'md' \| 'lg'` | `'md'` |
| `variant` | `variant` | `'ring' \| 'dots' \| 'shape' \| 'orbit'` | `'ring'` |
| `label` | `label` | `string` | `'Loading'` |

**CSS parts:** `base`
