`<moul-date-picker>` pairs a formatted field with a calendar in the top layer. Values are ISO `YYYY-MM-DD` strings.

<ComponentPreview align="start" minHeight="420px">
<div style="width: min(100%, 18rem)">
  <moul-date-picker label="Launch date" value="2026-10-24"></moul-date-picker>
</div>
</ComponentPreview>
