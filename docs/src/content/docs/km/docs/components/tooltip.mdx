`<moul-tooltip>` describes its trigger through `aria-describedby`. It opens immediately on keyboard focus and after `delay` on hover. Once one tooltip has shown, its siblings open instantly for a moment after the pointer leaves it, so moving along a toolbar doesn't wait at every button.

## API reference

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `content` | `content` | `string` | `''` |
| `placement` | `placement` | `'top' \| 'bottom' \| 'left' \| 'right'` | `'top'` |
| `delay` | `delay` | `number` | `300` |
| `is-open` | `isOpen` | `boolean` | `false` |

| Event | Type |
| :-- | :-- |
| `openchange` | `CustomEvent` |

| Slot | Description |
| :-- | :-- |
| `(default)` | — |
| `content` | — |

**CSS parts:** `popover`, `trigger`, `tooltip`
