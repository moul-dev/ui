# ComboBox (សមាសភាគ)

The `<moul-combobox>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

## Preview

  <moul-combobox-item value="waku">Waku</moul-combobox-item>
</moul-combobox>
</ComponentPreview>

## Import

```ts
import '@moul-dev/ui';
```

## HTML Usage

```html
<moul-combobox label="Framework">
  <moul-combobox-item value="astro">Astro</moul-combobox-item>
</moul-combobox>
```
