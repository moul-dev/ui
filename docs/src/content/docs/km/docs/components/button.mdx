# Button (សមាសភាគ)

The `<moul-button>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

## Import

```ts
import '@moul-dev/ui';
```

## HTML Usage

```html
<moul-button variant="primary">Click Me</moul-button>
```

## Attributes & Properties

| Name | Type | Default |
| :--- | :--- | :--- |
| `variant` | `ButtonVariant` | `'primary'` |
| `size` | `ButtonSize` | `'md'` |
| `type` | `ButtonType` | `'button'` |
| `is-icon` | `boolean` | `false` |
| `is-disabled` | `boolean` | `false` |
| `is-pending` | `boolean` | `false` |

| :--- | :--- |
