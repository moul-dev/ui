# Card (សមាសភាគ)

The `<moul-card>` component is a standards-first Web Component built with Lit 3 and styled with OKLCH CSS tokens.

## Import

```ts
import '@moul-dev/ui';
```

## HTML Usage

```html
<moul-card variant="outline">
  <moul-card-header>Title</moul-card-header>
  <moul-card-body>Body content</moul-card-body>
  <moul-card-footer>Actions</moul-card-footer>
</moul-card>
```

## Attributes & Properties

| Name | Type | Default |
| :--- | :--- | :--- |
| `tone` | `SemanticTone` | `'primary'` |
| `variant` | `VisualVariant` | `'flat'` |
| `is-interactive` | `boolean` | `false` |
