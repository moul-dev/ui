`<moul-stat>` shows a metric with its trend in a pill and an optional sparkline that runs to the card's edges. Hover the sparkline to read any day. New `value`s count in with a spring; the sparkline draws in once and then updates in place.

The value keeps the decimal places it was given, so `3.26` shows as `3.26`. Assign `valueFormatter` for anything else, such as compact numbers or currency.

## Scrubbing

Hover or drag across the sparkline and the card follows the nearest point: the value shows that point's number and the description shows its label from `sparklineLabels`. Move away and it returns to `value` and `description`. Give the points the same units as `value`, so the number reads the same while you scrub.

The sparkline is also a keyboard stop. Arrow keys step through the points from the latest, Home and End jump to either end, and Escape returns to the current value. Screen readers hear it as a slider whose value is the point's label and number.

## Trend sentiment

`trend` sets the triangle's direction. Its color says whether the change is good news: up is green, down is red. For metrics where lower is better, like churn, error rate, or latency, add `is-lower-better` and the colors swap.

## Sparkline color

The sparkline follows `tone`. To color it outside the semantic tones, set `color` to any CSS color, such as a chart palette step.

```html
<moul-stat label="Active users" value="10067" color="var(--color-chart-5)"></moul-stat>
```

## Variants

Set `variant` for a tinted card. The sparkline takes the card's text color on `flat`, `solid`, and `shadow`, and the tone color on `bordered` and `glass`.

## API reference

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `label` | `label` | `string` | `''` |
| `value` | `value` | `number` | `0` |
| `prefix` | `prefix` | `string` | `''` |
| `suffix` | `suffix` | `string` | `''` |
| `trend` | `trend` | `'up' \| 'down' \| 'neutral'` | `'neutral'` |
| `trend-value` | `trendValue` | `string` | `''` |
| `is-lower-better` | `isLowerBetter` | `boolean` | `false` |
| `tone` | `tone` | `'primary' \| 'accent' \| 'success' \| 'warning' \| 'error'` | `'primary'` |
| `variant` | `variant` | `'solid' \| 'flat' \| 'shadow' \| 'bordered' \| 'glass'` | `'flat'` |
| `color` | `color` | `string` | `''` |
| `description` | `description` | `string` | `''` |
| — | `sparklineData` | `number[]` | `undefined` |
| — | `sparklineLabels` | `string[]` | `undefined` |
| — | `valueFormatter` | `(value: number) => string` | `undefined` |

| Slot | Description |
| :-- | :-- |
| `icon` | Leading icon before the label |
| `footer` | Extra content under the description |

**CSS parts:** `header`, `label`, `icon`, `body`, `value-row`, `prefix`, `value`, `suffix`, `description`, `trend-badge`, `footer`, `sparkline`
