`<moul-input-otp>` splits a code across boxes, supports paste, and fires `complete` once every slot is filled.

## API reference

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `name` | `name` | `string` | `''` |
| `length` | `length` | `number` | `6` |
| `value` | `value` | `string` | `''` |
| `pattern` | `pattern` | `string` | `'^\\d+$'` |
| `is-disabled` | `isDisabled` | `boolean` | `false` |
| `is-required` | `isRequired` | `boolean` | `false` |
| `label` | `label` | `string` | `''` |

| Event | Type |
| :-- | :-- |
| `input` | `CustomEvent` |
| `change` | `CustomEvent` |
| `complete` | `CustomEvent` |

| Slot | Description |
| :-- | :-- |
| `label` | — |
| `separator` | — |

**CSS parts:** `group`, `base`, `label`, `slot`, `separator`
