`<moul-form>` collects every form-associated Moul input by `name`, runs constraint validation on submit and fires `submit` with the `FormData`.

## API reference

| Attribute | Property | Type | Default |
| :-- | :-- | :-- | :-- |
| `action` | `action` | `string` | `''` |
| `method` | `method` | `'get' \| 'post' \| 'dialog'` | `'post'` |
| `novalidate` | `novalidate` | `boolean` | `false` |

| Event | Type |
| :-- | :-- |
| `submit` | `CustomEvent` |
| `reset` | `CustomEvent` |
| `invalid` | `CustomEvent` |

| Slot | Description |
| :-- | :-- |
| `(default)` | — |

**CSS parts:** `base`
