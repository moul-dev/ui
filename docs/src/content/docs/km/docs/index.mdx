Moul UI គឺជាបណ្ណាល័យ Web Components ដែលងាយស្រួលប្រើ (Accessible) សម្រាប់ក្រុមការងារដែលចង់បាន UI ទំនើប និងស្របគ្នាតែមួយ នៅលើគ្រប់ Web Stack។

Component នីមួយៗគឺជា Custom Element ស្តង់ដារ បង្កើតឡើងលើ **Lit 3** និង **Shadow DOM** ហើយរចនាដោយ **CSS Design Token Layer (`light-dark()` + `oklch()`)** ដែលអាចកែសម្រួលបានភ្លាមៗ។ គ្រាន់តែ Register Elements ម្ដង រួចប្រើវាបានគ្រប់ទីកន្លែងដែល HTML ដំណើរការ។

## ការដំឡើង (Installation)

<Steps>
1. ### ដំឡើងកញ្ចប់កូដ

   <Tabs>
     <TabItem label="bun">
       ```bash
       bun add @moul-dev/ui
       ```
     </TabItem>
     <TabItem label="npm">
       ```bash
       npm install @moul-dev/ui
       ```
     </TabItem>
     <TabItem label="pnpm">
       ```bash
       pnpm add @moul-dev/ui
       ```
     </TabItem>
   </Tabs>

2. ### Import Stylesheet & Elements

   ```ts
   // Import global token definitions
   import '@moul-dev/ui/style.css';

   // Register all custom elements
   import '@moul-dev/ui';
   ```

3. ### ប្រើប្រាស់ Custom Elements ក្នុង HTML

   ```html
   <moul-button variant="primary">ចាប់ផ្តើម</moul-button>
   <moul-badge variant="success">សកម្ម</moul-badge>
   ```
