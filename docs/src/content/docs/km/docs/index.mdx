Moul UI គឺជាបណ្ណាល័យ Web Components ទំនើបដែលផ្អែកលើស្តង់ដារវេប សម្រាប់វិស្វករកម្មវិធីដែលចង់បានសមាសភាគ UI ប្រកបដោយភាពងាយស្រួលប្រើប្រាស់ (Accessibility) និងដំណើរការលឿន។

បង្កើតឡើងលើ **Lit 3**, **Shadow DOM**, និង **CSS Design Token Layer (`light-dark()` + `oklch()`)**។

## ការដំឡើង (Installation)

<Steps>
1. ### ដំឡើងកញ្ចប់កូដ

   <Tabs>
     <TabItem label="bun">
       ```bash
       bun add @moul-dev/ui
       ```
     </TabItem>
     <TabItem label="npm">
       ```bash
       npm install @moul-dev/ui
       ```
     </TabItem>
     <TabItem label="pnpm">
       ```bash
       pnpm add @moul-dev/ui
       ```
     </TabItem>
   </Tabs>

2. ### Import Stylesheet & Elements

   ```ts
   // Import global token definitions
   import '@moul-dev/ui/style.css';

   // Register all custom elements
   import '@moul-dev/ui';
   ```

3. ### ប្រើប្រាស់ Custom Elements ក្នុង HTML

   ```html
   <moul-button variant="primary">ចាប់ផ្តើម</moul-button>
   <moul-badge variant="success">សកម្ម</moul-badge>
   ```
