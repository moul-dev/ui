# Skeleton

The `Skeleton` component is an accessible animated placeholder used to render loading states that simulate layout content while data is loading.

## Shape Variants

`Skeleton` supports three shape variants: `block` (default), `text`, and `circle`:

<ComponentPreview>
  <div class="flex flex-col gap-4 w-72">
    <div>
      <span class="text-xs text-neutral-400 mb-1 block">Block (variant="block")</span>
      <moul-skeleton variant="block" ></moul-skeleton>
    </div>
    <div>
      <span class="text-xs text-neutral-400 mb-1 block">Text Line (variant="text")</span>
      <moul-skeleton variant="text" ></moul-skeleton>
    </div>
    <div>
      <span class="text-xs text-neutral-400 mb-1 block">Circle / Avatar (variant="circle")</span>
      <moul-skeleton variant="circle" ></moul-skeleton>
    </div>
  </div>
</ComponentPreview>

```tsx
// Rectangular block placeholder
<moul-skeleton variant="block" ></moul-skeleton>

// Text line placeholder
<moul-skeleton variant="text" ></moul-skeleton>

// Circular avatar / icon placeholder
<moul-skeleton variant="circle" ></moul-skeleton>
```

## Multi-item Count

Use the `count` prop to render multiple stacked skeleton items with automatic spacing:

<ComponentPreview>
  <div class="w-72">
    <moul-skeleton variant="text" count={4} ></moul-skeleton>
  </div>
</ComponentPreview>

```tsx
<moul-skeleton variant="text" count={4} ></moul-skeleton>
```
