## Dot Status Indicators

Enable the `dot` prop or use `variant="dot"` to display a circular status indicator alongside your label:

<ComponentPreview>
  <div class="flex items-center gap-3 flex-wrap">
    <moul-badge variant="dot">Status Dot</moul-badge>
    <moul-badge variant="success" dot>Operational</moul-badge>
    <moul-badge variant="warning" dot>Degraded</moul-badge>
    <moul-badge variant="error" dot>Incident</moul-badge>
    <moul-badge variant="primary" dot>Deploying</moul-badge>
  </div>
</ComponentPreview>

```tsx
// Standalone status dot
<moul-badge variant="dot">Status Dot</moul-badge>

// Semantic color dots
<moul-badge variant="success" dot>Operational</moul-badge>
<moul-badge variant="warning" dot>Degraded</moul-badge>
<moul-badge variant="error" dot>Incident</moul-badge>
<moul-badge variant="primary" dot>Deploying</moul-badge>
```
