# Button

## Preview



The `Button` component is built with React Aria and styled using StyleX.

## Variants

You can customize the appearance of the button using the `variant` prop:

## Usage

Here is a basic example of how to use the `Button` component:

```tsx


export default function Example() {
  return (
    <moul-button>
      {/* Component content */}
    </moul-button>
  );
}
```

| Render Prop | CSS Selector |
| :--- | :--- |
| `isHovered` <br/> Whether the button is currently hovered. | `[data-hovered]` |
| `isPressed` <br/> Whether the button is currently pressed. | `[data-pressed]` |
| `isFocused` <br/> Whether the button is focused. | `[data-focused]` |
| `isFocusVisible` <br/> Whether the button is keyboard focused. | `[data-focus-visible]` |
| `isDisabled` <br/> Whether the button is disabled. | `[data-disabled]` |
| `isPending` <br/> Whether the button is in a pending state. | `[data-pending]` |
