# ToggleButtonGroup

A toggle button group represents a set of related buttons that can be toggled on or off, supporting both single and multiple selection.

## Examples

### Classic adjacent group

By default, the buttons in a `ToggleButtonGroup` touch and share border radiuses, showing a unified toolbar appearance:

```tsx
<moul-toggle-button-group defaultValue={['left']}>
  <moul-toggle-button id="left">Left</moul-toggle-button>
  <moul-toggle-button id="center">Center</moul-toggle-button>
  <moul-toggle-button id="right">Right</moul-toggle-button>
</moul-toggle-button-group>
```

### Icon Toolbar

You can render icons inside the `<moul-toggle-button>` components. When rendering icon-only buttons, make sure to add an `aria-label` to each button for accessibility:

```tsx



export default function Example() {
  return (
    <moul-toggle-button-group selectionMode="multiple" defaultValue={['bold', 'underline']}>
      <moul-toggle-button id="bold" aria-label="Bold">
        <strong>B</strong>
      </moul-toggle-button>
      <moul-toggle-button id="italic" aria-label="Italic">
        <em>I</em>
      </moul-toggle-button>
      <moul-toggle-button id="underline" aria-label="Underline">
        <u>U</u>
      </moul-toggle-button>
    </moul-toggle-button-group>
  );
}
```

### Animated Segmented Control

Use the `animated` prop to style the group as a modern segmented control with a sliding selection indicator.

```tsx
<moul-toggle-button-group animated defaultValue="day">
  <moul-toggle-button id="day">Day</moul-toggle-button>
  <moul-toggle-button id="week">Week</moul-toggle-button>
  <moul-toggle-button id="month">Month</moul-toggle-button>
</moul-toggle-button-group>
```
