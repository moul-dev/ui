# TextArea

## Preview

<ComponentPreview>
  <moul-text-area label="Bio" placeholder="Tell us about yourself..." description="Must be under 200 words." class="w-80" ></moul-text-area>
</ComponentPreview>

The `TextArea` component is built with React Aria and styled using StyleX. It automatically handles layout composition for label, description, and validation error messages.

## Features

### Label
The text area automatically renders an accessible `<moul-label>` element above the text area input when the `label` prop is provided.

<ComponentPreview>
  <moul-text-area label="Bio" placeholder="Tell us about yourself..." class="w-80" ></moul-text-area>
</ComponentPreview>

```tsx
<moul-text-area label="Bio" placeholder="Tell us about yourself..." ></moul-text-area>
```

### Description
Use the `description` prop to display help text or guidelines below the text area input. This automatically wires up accessibility relationships so assistive technologies can read it.

<ComponentPreview>
  <moul-text-area
    label="Comments"
    description="Please do not include sensitive personal information."
    class="w-80"
  ></moul-text-area>
</ComponentPreview>

```tsx
<moul-text-area
  label="Comments"
  description="Please do not include sensitive personal information."
></moul-text-area>
```

### Validation & FieldError
If the input is invalid, you can provide an error message using the `errorMessage` prop. This renders a `<moul-field-error>` component automatically when the field validation fails.

<ComponentPreview>
  <moul-text-area
    label="Message"
    isRequired
    is-invalid
    error-message="Please enter your message."
    class="w-80"
  ></moul-text-area>
</ComponentPreview>

```tsx
<moul-text-area
  label="Message"
  isRequired
  is-invalid
  error-message="Please enter your message."
></moul-text-area>
```

#### Standalone ErrorMessage
For manual or custom validation outside of the built-in `errorMessage` prop, you can use `FieldError`:

```html
<moul-field-error>Invalid input description.</moul-field-error>
```

## Usage

Here is a basic example of a configured `TextArea`:

```tsx


export default function Example() {
  return (
    <moul-text-area
      label="Description"
      placeholder="Briefly describe your project..."
      description="Max 500 characters."
      isRequired
      error-message="A description is required."
    ></moul-text-area>
  );
}
```
