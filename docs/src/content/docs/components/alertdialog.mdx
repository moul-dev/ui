## Usage

Here is a basic example of how to use the `AlertDialog` component:

```tsx


export default function Example() {
  return (
    <moul-alert-dialog>
      <div slot="header">Deactivate Account</div>
      <div slot="body">
        Are you sure you want to deactivate your account? This action cannot be undone.
      </div>
      <div slot="footer">
        <moul-button variant="outline" onPress={() => {}}>Cancel</moul-button>
        <moul-button variant="danger" onPress={() => {}}>Confirm</moul-button>
      </div>
    </moul-alert-dialog>
  );
}
```
