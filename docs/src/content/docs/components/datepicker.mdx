# DatePicker

A form input component combining accessible partitioned date fields with interactive calendar dropdowns.

## Preview



## Installation

```tsx

```

## Basic DatePicker

```tsx
<moul-date-picker
  label="Meeting Date"
  description="Select your preferred meeting date"
></moul-date-picker>
```

## DateRangePicker

Use `DateRangePicker` for booking reservations or analytics date filtering:

```tsx
<moul-date-range-picker
  label="Stay Duration"
  description="Select check-in and check-out dates"
></moul-date-range-picker>
```

## DateField

Use `DateField` when a standalone masked date input without a popover calendar is desired:

```tsx
<moul-date-picker
  label="Birth Date"
  description="Enter in MM/DD/YYYY format"
/>
```

## Validation & States

```tsx
<moul-date-picker
  label="Expiry Date"
  is-invalid
  error-message="Please select a valid future date"
></moul-date-picker>
```

## Props

### DatePicker & DateRangePicker

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `label` | `string` | — | Accessible label for the input |
| `description` | `string` | — | Help text rendered below the input |
| `errorMessage` | `string \| ((v) => string)` | — | Error message shown when invalid |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Size variant |
| `variant` | `'primary' \| 'secondary'` | `'primary'` | Visual background variant |
| `isDisabled` | `boolean` | `false` | Whether the input is disabled |
| `isInvalid` | `boolean` | `false` | Marks the field as invalid |
| `minValue` | `DateValue` | — | Earliest selectable date |
| `maxValue` | `DateValue` | — | Latest selectable date |
