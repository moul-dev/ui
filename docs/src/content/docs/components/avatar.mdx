# Avatar

The `Avatar` component represents users or entities with support for image loading, initials fallback, default silhouette fallback, online/offline status dots, and overlapping `AvatarGroup` stacks.

## Sizes

Avatars come in six standardized sizes: `xs` (24px), `sm` (32px), `md` (40px, default), `lg` (48px), `xl` (56px), and `2xl` (64px).

    <moul-avatar initials="MD" size="md" aria-label="Medium avatar" ></moul-avatar>
    <moul-avatar initials="LG" size="lg" aria-label="Large avatar" ></moul-avatar>

  </div>
</ComponentPreview>

## AvatarGroup

Use `AvatarGroup` to stack multiple avatars together with negative overlap. Set the `max` prop to automatically display the remaining count with a `+N` badge.

<ComponentPreview>
  <div class="flex flex-col gap-6">
    <moul-avatar-group max={3} aria-label="Team members">
      <moul-avatar initials="AL" aria-label="Alex" ></moul-avatar>
      <moul-avatar initials="BT" aria-label="Beth" ></moul-avatar>
      <moul-avatar initials="CK" aria-label="Chris" ></moul-avatar>
      <moul-avatar initials="DL" aria-label="Dana" ></moul-avatar>
      <moul-avatar initials="EV" aria-label="Evan" ></moul-avatar>
    </moul-avatar-group>

    <moul-avatar-group size="sm" shape="square" max={4} aria-label="Engineers group">
      <moul-avatar initials="E1" aria-label="Dev 1" ></moul-avatar>
      <moul-avatar initials="E2" aria-label="Dev 2" ></moul-avatar>
      <moul-avatar initials="E3" aria-label="Dev 3" ></moul-avatar>
      <moul-avatar initials="E4" aria-label="Dev 4" ></moul-avatar>
      <moul-avatar initials="E5" aria-label="Dev 5" ></moul-avatar>
    </moul-avatar-group>
  </div>
</ComponentPreview>

```tsx
<moul-avatar-group max={3} aria-label="Team members">
  <moul-avatar initials="AL" aria-label="Alex" ></moul-avatar>
```
