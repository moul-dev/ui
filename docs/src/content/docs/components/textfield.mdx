# TextField

## Preview



The `TextField` component is built with React Aria and styled using StyleX. It automatically handles layout composition for label, description, and validation error messages.

## Features

### Label
The text field automatically renders an accessible `<moul-label>` element above the input when the `label` prop is provided.

<ComponentPreview>
  <moul-text-field label="Full Name" placeholder="John Doe" class="w-80" ></moul-text-field>
</ComponentPreview>

```tsx
<moul-text-field label="Full Name" placeholder="John Doe" ></moul-text-field>
```

### Description
Use the `description` prop to display help text or guidelines below the input field. This automatically wires up accessibility relationships so assistive technologies can read it.

<ComponentPreview>
  <moul-text-field
    label="Password"
    type="password"
    description="Must be at least 8 characters long."
    class="w-80"
  ></moul-text-field>
</ComponentPreview>

```tsx
<moul-text-field
  label="Password"
  type="password"
  description="Must be at least 8 characters long."
></moul-text-field>
```

### Validation & FieldError
If the input is invalid, you can provide an error message using the `errorMessage` prop. This renders a `<moul-field-error>` component automatically when the field validation fails.

<ComponentPreview>
  <moul-text-field
    label="Email"
    type="email"
    isRequired
    is-invalid
    error-message="Please enter a valid email address."
    class="w-80"
  ></moul-text-field>
</ComponentPreview>

```tsx
<moul-text-field
  label="Email"
  type="email"
  isRequired
  is-invalid
  error-message="Please enter a valid email address."
></moul-text-field>
```

#### Standalone ErrorMessage
For manual or custom validation outside of the built-in `errorMessage` prop, you can use `FieldError`:

```html
<moul-field-error>Invalid email address format.</moul-field-error>
```

## Usage

Here is a basic example of a configured `TextField`:

```tsx


export default function Example() {
  return (
    <moul-text-field
      label="Username"
      placeholder="e.g. janesmith"
      description="Your unique handle on the platform."
      isRequired
      error-message="Username is required."
    ></moul-text-field>
  );
}
```
