# Pagination

The `Pagination` component enables users to navigate across large datasets divided into multiple pages. It features automatic sibling truncation ellipses, rows-per-page selection dropdowns, total summary counts, and complete ARIA landmark semantics.

## Basic Usage

Pass `page`, `totalPages`, and `onChange` for standard controlled pagination:

<ComponentPreview>
  <div class="flex flex-col gap-4 w-full max-w-xl">
    <moul-pagination page={3} total-pages={10} ></moul-pagination>
  </div>
</ComponentPreview>

```tsx



export default function Example() {
  const [page, setPage] = useState(1);

  return (
    <moul-pagination
      page={page}
      total-pages={10}
      onChange={setPage}
    ></moul-pagination>
  );
}
```

## With Summary and Page Size Selector

Enable `showSummary` and `showPageSize` to provide complete data table navigation:

<ComponentPreview>
  <div class="flex flex-col gap-4 w-full max-w-2xl">
    <moul-pagination
      page={2}
      total={250}
      pageSize={10}
      showSummary
      showPageSize
      showFirstLast
      showPrevNext
    ></moul-pagination>
  </div>
</ComponentPreview>

```tsx



export default function Example() {
  const [page, setPage] = useState(1);
  const [pageSize, setPageSize] = useState(10);

  return (
    <moul-pagination
      page={page}
      total={250}
      pageSize={pageSize}
      showSummary
      showPageSize
      showFirstLast
      showPrevNext
      onChange={setPage}
      onPageSizeChange={setPageSize}
    ></moul-pagination>
  );
}
```
