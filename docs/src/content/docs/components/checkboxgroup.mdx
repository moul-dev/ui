## Usage

Here is a basic example of how to use the `CheckboxGroup` component:

```tsx


export default function Example() {
  return (
    <moul-checkbox-group label="Settings" description="Configure your preferences">
      <moul-checkbox value="cookies">Accept cookies</moul-checkbox>
      <moul-checkbox value="marketing">Receive marketing</moul-checkbox>
    </moul-checkbox-group>
  );
}
```

## Features

### Group Variants
Setting `variant` on `CheckboxGroup` propagates the variant style (`primary`, `secondary`, or `tertiary`) to all nested `Checkbox` components automatically.

<ComponentPreview>
  <div class="flex flex-col gap-6">
    <moul-checkbox-group label="Primary Group" variant="primary">
      <moul-checkbox value="1" defaultSelected>Checkbox A</moul-checkbox>
      <moul-checkbox value="2">Checkbox B</moul-checkbox>
    </moul-checkbox-group>
    
    <moul-checkbox-group label="Secondary Group" variant="secondary">
      <moul-checkbox value="1" defaultSelected>Checkbox A</moul-checkbox>
      <moul-checkbox value="2">Checkbox B</moul-checkbox>
    </moul-checkbox-group>

    <moul-checkbox-group label="Tertiary Group" variant="tertiary">
      <moul-checkbox value="1" defaultSelected>Checkbox A</moul-checkbox>
      <moul-checkbox value="2">Checkbox B</moul-checkbox>
    </moul-checkbox-group>
  </div>
</ComponentPreview>

```tsx
// Nested checkboxes inherit the group's secondary variant
<moul-checkbox-group label="Roles" variant="secondary">
  <moul-checkbox value="admin">Admin</moul-checkbox>
  <moul-checkbox value="user">User</moul-checkbox>
</moul-checkbox-group>
```

### Orientation
Lays out checkboxes vertically (default) or horizontally using the `orientation` prop.

<ComponentPreview>
  <moul-checkbox-group label="Horizontal Layout" orientation="horizontal" variant="primary">
    <moul-checkbox value="vertical">Vertical option</moul-checkbox>
    <moul-checkbox value="horizontal" defaultSelected>Horizontal option</moul-checkbox>
    <moul-checkbox value="grid">Grid option</moul-checkbox>
  </moul-checkbox-group>
</ComponentPreview>

```tsx
<moul-checkbox-group label="Horizontal Layout" orientation="horizontal">
  <moul-checkbox value="1">Option 1</moul-checkbox>
  <moul-checkbox value="2">Option 2</moul-checkbox>
</moul-checkbox-group>
```
