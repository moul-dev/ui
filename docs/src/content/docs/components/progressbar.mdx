# ProgressBar

The `ProgressBar` component visually indicates the status of an ongoing operation, supporting determinate percentage values, indeterminate animated loading bars, custom metric labels, and semantic color variants.

## Determinate vs Indeterminate

`ProgressBar` handles both bounded progress (e.g. `value={65}`) and indefinite loading states (`isIndeterminate={true}`):

<ComponentPreview>
  <div class="flex flex-col gap-5 w-full max-w-xl">
    <moul-progress-bar label="Determinate (45%)" value={45} ></moul-progress-bar>
    <moul-progress-bar label="Indeterminate (Loading...)" isIndeterminate ></moul-progress-bar>
  </div>
</ComponentPreview>

```tsx
// Determinate
<moul-progress-bar label="Determinate (45%)" value={45} ></moul-progress-bar>

// Indeterminate linear bar
<moul-progress-bar label="Indeterminate (Loading...)" isIndeterminate ></moul-progress-bar>
```

## Sizes and Shapes

Select from `sm` (4px), `md` (8px), and `lg` (12px) track heights, and `pill` or `square` corners:

<ComponentPreview>
  <div class="flex flex-col gap-5 w-full max-w-xl">
    <moul-progress-bar label="Small (sm) - Pill" value={40} size="sm" shape="pill" ></moul-progress-bar>
    <moul-progress-bar label="Medium (md) - Pill" value={60} size="md" shape="pill" ></moul-progress-bar>
    <moul-progress-bar label="Large (lg) - Pill" value={80} size="lg" shape="pill" ></moul-progress-bar>
    <moul-progress-bar label="Square Shape" value={70} shape="square" size="md" ></moul-progress-bar>
  </div>
</ComponentPreview>

```tsx
<moul-progress-bar label="Small (sm)" value={40} size="sm" shape="pill" ></moul-progress-bar>
<moul-progress-bar label="Medium (md)" value={60} size="md" shape="pill" ></moul-progress-bar>
<moul-progress-bar label="Large (lg)" value={80} size="lg" shape="pill" ></moul-progress-bar>
<moul-progress-bar label="Square Shape" value={70} shape="square" ></moul-progress-bar>
```

## Custom Value Labels

Use `valueLabel` to display formatted quantities, storage metrics, or steps:

<ComponentPreview>
  <div class="flex flex-col gap-4 w-full max-w-xl">
    <moul-progress-bar
      label="Cloud Storage"
      value={65}
      valueLabel="6.5 GB / 10 GB"
      showValueText
    ></moul-progress-bar>
    <moul-progress-bar
      label="Onboarding Wizard"
      value={60}
      valueLabel="Step 3 of 5"
      showValueText
      variant="accent"
    ></moul-progress-bar>
  </div>
</ComponentPreview>

```tsx
<moul-progress-bar
  label="Cloud Storage"
  value={65}
  valueLabel="6.5 GB / 10 GB"
  showValueText
></moul-progress-bar>

<moul-progress-bar
  label="Onboarding Wizard"
  value={60}
  valueLabel="Step 3 of 5"
  showValueText
  variant="accent"
></moul-progress-bar>
```
