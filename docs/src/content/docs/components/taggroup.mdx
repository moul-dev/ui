# TagGroup

A tag group is a focusable list of labels, categories, keywords, filters, or other items, with support for keyboard navigation, selection, and removal.

## Preview



The `TagGroup` component is built with React Aria and styled using StyleX.

## Usage

Here is a basic example of how to use the `TagGroup` component:

```tsx


export default function Example() {
  return (
    <moul-tag-group label="Categories">
      <moul-tag>News</moul-tag>
      <moul-tag>Travel</moul-tag>
      <moul-tag>Gaming</moul-tag>
      <moul-tag>Shopping</moul-tag>
    </moul-tag-group>
  );
}
```

## Variants

TagGroup and Tag support three variants: `primary`, `secondary` (default), and `tertiary`. You can pass the variant to the `TagGroup` to apply it to all tags, or override it on individual `Tag`s.

```tsx
<moul-tag-group label="Primary Tags" variant="primary">
  <moul-tag>Analytics</moul-tag>
  <moul-tag>Security</moul-tag>
</moul-tag-group>

<moul-tag-group label="Secondary Tags" variant="secondary">
  <moul-tag>Analytics</moul-tag>
  <moul-tag>Security</moul-tag>
</moul-tag-group>

<moul-tag-group label="Tertiary Tags" variant="tertiary">
  <moul-tag>Analytics</moul-tag>
  <moul-tag>Security</moul-tag>
</moul-tag-group>
```

## Sizes

TagGroup and Tag support three sizes: `sm`, `md` (default), and `lg`. You can set the size on the `TagGroup` to apply it to all tags, or override it on individual `Tag`s.

```tsx
<moul-tag-group label="Small" size="sm">
  <moul-tag>Small tag</moul-tag>
</moul-tag-group>

<moul-tag-group label="Medium" size="md">
  <moul-tag>Medium tag</moul-tag>
</moul-tag-group>

<moul-tag-group label="Large" size="lg">
  <moul-tag>Large tag</moul-tag>
</moul-tag-group>
```

## Selection

Use the `selectionMode` prop to enable single or multiple selection.

```tsx




export default function Example() {
  const [selected, setSelected] = useState<code>&lt;Selection&gt;</code>(new Set(['news']));

  return (
    <moul-tag-group
      label="Categories"
      selectionMode="multiple"
      selectedKeys={selected}
      onSelectionChange={setSelected}
    >
      <moul-tag id="news">News</moul-tag>
      <moul-tag id="travel">Travel</moul-tag>
      <moul-tag id="gaming">Gaming</moul-tag>
    </moul-tag-group>
  );
}
```

## Removal

Pass an `onRemove` callback to the `TagGroup` component to allow items to be removed. When specified, tags will automatically render close buttons suited to their sizes and variants.

```tsx



export default function Example() {
  const [tags, setTags] = useState([
    { id: '1', label: 'News' },
    { id: '2', label: 'Travel' },
    { id: '3', label: 'Gaming' },
  ]);

  const handleRemove = (keys) => {
    setTags((prev) => prev.filter((tag) => !keys.has(tag.id)));
  };

  return (
    <moul-tag-group label="Categories" onRemove={handleRemove}>
      {tags.map((tag) => (
        <moul-tag key={tag.id} id={tag.id}>
          {tag.label}
        </moul-tag>
      ))}
    </moul-tag-group>
  );
}
```
