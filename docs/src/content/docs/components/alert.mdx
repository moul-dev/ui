# Alert

## Preview



The `Alert` component is built with React Aria and styled using StyleX. It supports multiple status variants, inline action buttons, close triggers, and rich custom layout slots.

```tsx

```

## Actions and Closable

Alerts can accept an optional inline action element or a close button using `action` and `onClose` props:

<ComponentPreview>
  <div class="flex flex-col gap-4 w-full max-w-2xl">
    <moul-alert
      variant="primary"
      title="Update available"
      description="A new version is ready to install."
    >
      <moul-button slot="actions" variant="primary" size="sm">Refresh</moul-button>
    </moul-alert>
    <moul-alert variant="primary" title="Interactive Alert">This is a dynamic alert demonstration.</moul-alert>
  </div>
</ComponentPreview>

```html
<moul-alert
  variant="primary"
  title="Update available"
  description="A new version is ready to install."
>
  <moul-button slot="actions" variant="primary" size="sm">Refresh</moul-button>
</moul-alert>

<moul-alert
  variant="success"
  title="Profile updated successfully"
  is-dismissable
></moul-alert>
```

## Rich Content (Children)

You can pass custom children inside the `Alert` component to display nested lists, custom spacing, or elements:

<ComponentPreview>
  <div class="flex flex-col gap-4 w-full max-w-2xl">
    <moul-alert
      variant="danger"
      title="Unable to connect to server"
    >
      <moul-button slot="actions" variant="danger" size="sm">Retry</moul-button>
      <div style="margin-top: 8px; font-size: 14px; opacity: 0.9;">
        <p style="margin: 0 0 8px 0;">We're experiencing connection issues. Please try the following:</p>
        <ul style="list-style-type: disc; padding-left: 20px; margin: 0; display: flex; flex-direction: column; gap: 4px;">
          <li>Check your internet connection</li>
          <li>Refresh the page</li>
          <li>Clear your browser cache</li>
        </ul>
      </div>
    </moul-alert>
  </div>
</ComponentPreview>

```html
<moul-alert
  variant="danger"
  title="Unable to connect to server"
>
  <moul-button slot="actions" variant="danger" size="sm">Retry</moul-button>
  <div class="mt-2 text-sm">
    <p class="mb-2">We're experiencing connection issues. Please try the following:</p>
    <ul>
      <li>Check your internet connection</li>
      <li>Refresh the page</li>
      <li>Clear your browser cache</li>
    </ul>
  </div>
</moul-alert>
```
