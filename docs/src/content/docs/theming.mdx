## Custom Properties Reference

| Variable | Default | Description |
|---|---|---|
| `--moul-brand-hue` | `250` | Base brand hue (0 - 360) |
| `--moul-brand-radius-factor` | `1` | Multiplier for border radius scaling |
| `--moul-brand-density-factor` | `1` | Multiplier for padding and component sizing |
| `--moul-brand-font-scale` | `1` | Multiplier for typography scaling |

## Dark Mode Support

Moul UI components inherit Bootstrap 6 dark mode styling seamlessly. Set `data-bs-theme="dark"` on any ancestor element or `<html>`:

```html
<html data-bs-theme="dark">
  ...
</html>
```
